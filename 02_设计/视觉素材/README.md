## 裁决边界

- 图片中的示例文字、日期、数量和附件内容仅用于说明布局，不是要写入产品的数据。
- 页面图确认页面结构、内容密度、主要动作位置和小票专属材质方向；“梅墨雾白”图确认整体色彩关系。精确色值以设计规格的语义颜色表为准。
- 小票分镜确认可观察的视觉与交互关系，不把生成图中的示例票据正文、日期、数量或局部渲染误差写入产品；确认页标题“已结束本轮构思”不改变“生成小票”成功落盘时才原子化结束的业务规则。
- “原位渐进”图只确认完整状态的视觉处理方式，不逐像素批准生成图，也不批准其中的业务推断。图中任何左右卡片流暗示、入口语义、对象数量、状态文案或页面归属偏差均作废；卡片预览必须保持居中单卡、上下切换和单一“归入构思集”入口，四页“+”始终只新增灵感。
- 石墨雾绿、黑白暗莓、极光梅雾、银白朱砂和梅夜显影均为未采用探索，不进入实现目标。
- “梅墨聚焦”和“光学层次”均为未采用的共享组件探索，不进入实现目标。
- “分层聚焦”和“自适应呼吸”完整状态探索均未采用，不进入实现目标。
- 小票的纸张语言只属于构思小票对象，不扩展为全 App 纸张主题。
- 图片为设计参考，不得标记为 `runtime`，不得替代模拟器、真机或自动化验收证据。
- 后续若确认稿与图片局部表现冲突，以三份唯一现役合同中的最新明确条款为准。
