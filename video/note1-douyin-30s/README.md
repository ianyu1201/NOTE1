# NOTE1 抖音 30 秒样片

这是基于 `docs/推广资料/NOTE1_抖音口播稿.md` 和 `media/demo/` 中真实运行态截图制作的 1080×1920 Remotion 工程。当前版本含约 30 秒的普通话合成旁白（macOS 本机高级音色 `Yue`）与同步画面字幕，便于先确认镜头、节奏与内容边界。

## 分镜

| 时间 | 画面 | 口播重点 |
| --- | --- | --- |
| 0–4 秒 | 首页 | 找不到适合自己的备忘录，因此做了 NOTE1 |
| 4–10 秒 | 首页 | 快速记录文字、照片和文件 |
| 10–16 秒 | 卡片回看 | 上下切换、左右完成、继续写 |
| 16–20 秒 | 编辑 | 加入灵感组 |
| 20–24 秒 | 灵感组 | 回看自己的想法，而不是刷信息流 |
| 24–30 秒 | 历史 | 测试阶段与评论区反馈 CTA |

## 使用

```bash
npm install
npm run studio
npm run render
```

渲染产物在 `out/note1-douyin-30s.mp4`，封面静帧运行 `npm run still`。下一轮可将静态截图替换为真机或模拟器连续录屏；如更换配音，只需替换 `public/audio/narration.m4a`。不要用 AI 功能或云同步相关画面，因为它们不属于当前 NOTE1 产品范围。
