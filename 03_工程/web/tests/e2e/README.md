# NOTE1 Web 业务闭环测试

这里复用 2026-10-09 双端测试中已完成复验的五份 Web 脚本。业务断言与合成数据保持原样；适配只涉及 Playwright 依赖、服务地址、浏览器选择、产物目录及统一失败退出码。此目录不包含历史运行结果。

在 `web` 目录安装依赖和浏览器：

```sh
npm ci
npx playwright install chromium
```

先在一个终端启动本地应用：

```sh
npm run dev -- --host 127.0.0.1 --port 5173
```

再在另一个终端运行全部 45 项检查：

```sh
npm run test:e2e
```

可使用已启动的开发或预览服务。`BASE_URL` 指向完整演示页地址，默认是 `http://127.0.0.1:5173/portfolio/note1/demo/`：

```sh
BASE_URL=http://127.0.0.1:4173/portfolio/note1/demo/ npm run test:e2e
```

默认使用 Playwright 自带 Chromium。如需使用本机 Google Chrome，可设置 `BROWSER_CHANNEL=chrome`。可用 `E2E_OUTPUT_DIR` 指定产物目录；默认输出至被 Git 忽略的 `.test-results/note1-e2e/<时间戳>/`。`summary.json` 汇总 45 项断言；任何断言失败、结果缺失、未捕获浏览器错误或脚本异常都会使命令以非零状态退出。

| 脚本 | 范围 | 覆盖 |
| --- | --- | --- |
| `web-audit.cjs` | W01–W16 | 四个页面的新建/取消、保存及刷新后持久化、编辑、附件、卡片收起撤回、归入构思集、生成小票、快照不变、搜索、文本导出、备份恢复、历史与窄屏 |
| `supplemental.cjs` | W17–W27 | 重开标签页、第二轮构思与小票、删除恢复、永久删除确认、键盘焦点、写入失败保护、多标签页、缺少 IndexedDB、备份摘要校验、大字号 |
| `boundaries.cjs` | W28–W34 | 六个构思集、十一条成员、工作台编辑排序与移出、生成失败回滚、双击防重、附件字节恢复、未来版本只读保护 |
| `backup-deletion.cjs` | W35–W37 | 删除构思集保留小票、删除后的备份恢复、清空回收站保留小票附件 |
| `fix-regressions.cjs` | E01–E08 | 无广播的并发写入、最新备份、广播刷新保留草稿、小票删除取消与恢复、清空确认焦点、历史续写、失败重试、历史分类、跨构思集成员归属 |

脚本会为每个浏览器上下文创建独立本地数据，使用固定的测试文本与附件；备份和状态文件由首个批次生成，后续批次复用，因此请通过 `run.cjs` 按顺序执行。测试不会访问已有浏览器用户资料。此套测试只覆盖 Web 端；不替代原生真机语音、VoiceOver 或原生系统文件保存/恢复验收。PDF 检查只确认浏览器打印输出能生成文件，不验收系统打印对话框。
