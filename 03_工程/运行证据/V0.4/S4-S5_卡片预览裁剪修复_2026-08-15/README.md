# V0.4 卡片预览裁剪修复运行证据

身份：`superseded runtime`。该批次只修复了纸面裁剪和静止相邻纸面，仍把卡片切换限制在独立矩形视口，未解决用户指出的动态模块分层与一体感问题。不得继续作为当前实现证据；取代证据见 `../S4-S5_卡片预览连续舞台修复_2026-08-15/README.md`。

## 根因与修复

- 根因：纸面填满拖拽视口并贴住 `.clipped()` 边界，导致底部圆角、描边和阴影被截断；静止相邻卡同时使用完整高度纸面，放大了平直截面与下方画布割裂感；
- 修复：纸面与拖拽视口分离，纸面上下各保留 18pt 安全距离；静止相邻卡改为 28pt 受控薄边提示，完整相邻卡只在实际拖拽时进入视口；
- 保持：页码位于“归入构思集”上方，业务操作、上下手势、画布颜色和底部导航不变。
