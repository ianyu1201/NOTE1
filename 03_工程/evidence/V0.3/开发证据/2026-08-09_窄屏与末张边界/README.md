# NOTE1 V0.3 窄屏与末张边界证据索引

> 日期：2026-08-09
> 性质：细节优化第六批运行抽样，不是用户确认的最终视觉稿

## 1. 本批范围

- 在 `NOTE1 Small Evidence`（iPhone 13 mini / `iPhone14,4`，iOS 26.5 模拟器）复核卡片预览的窄屏、附件、长内容和最大辅助字号状态；
- 在同一窄屏设备复核 13 张小票中的末张短票、最大辅助字号纵向阅读、票尾统计和末张继续向后拖拽的阻尼/不循环结果；
- 修复小票页码胶囊在最大辅助字号下被放大成两行的问题：上下文页码使用与卡片页一致的 `1.25×` 缩放上限和单行规则，票面正文仍保持完整动态字体；
- 重新完成主模拟器与窄屏模拟器构建，并运行 80 项 XCTest。

## 4. 证据边界

- 本批关闭的是 iOS 26.5 模拟器上的窄屏/字号布局与末张运行边界，不替代真机触感、VoiceOver、减少透明度或 iOS 17–25 材质降级；
- 171 字夹具只证明卡片预览按既定 7 行摘要规则重排且操作不丢失；完整文字仍须点按进入编辑页阅读；
- 归入按钮的 0/5 个构思集、10 条满额组合和真实手指一次连续长按上拖未由本批关闭；
- 当前卡片堆、归入按钮和四页最终视觉仍需用户确认，不得由本批抽样写成 S3 已冻结。
