# NOTE1 V0.3 短票与手势边界证据索引

> 日期：2026-08-09  
> 性质：细节优化第四批运行抽样，不是用户确认的最终视觉稿

## 1. 本批范围

- 以唯一现役黑白热敏票据参考为对照，修复一条文字、无附件经典票被固定高度拉成普通长白卡的问题；
- 短票继续保留票据夹、冷白纸面、齿边、居中票头、双线/虚线和打印层级，只收紧正文结束后的空白尾；
- 首张向前和末张向后均保持不循环；越界拖拽显示 24% 阻尼，未过 88pt 换票阈值回弹；
- 减少动态效果下缩短换票位移与时长，但保持对象结果、回弹与页码关系。

唯一现役参考：`../../确认视觉/NOTE1_V0.3_小票黑白热敏票据参考.png`。

## 3. 运行环境与结果

| 场景 | 环境 | 结果 |
| --- | --- | --- |
| 默认字号短票前后对照 | NOTE1 Evidence iPhone 15 Pro，iOS 26.5 模拟器，浅色、默认字号 | 一条灵感经典票由固定 560pt 空白尾收为 468pt 内容高度；字段、纸边、票据夹和页码完整 |
| 正常动态手势 | 同上 | 88pt 以下回弹；首张反向拖拽出现阻尼且不循环；有效方向仍可切换相邻小票 |
| 减少动态效果 | 同上；录制前系统 `ReduceMotionEnabled` 查询为 `1` | 换票使用缩短位移与时长；未过阈值仍回弹，结果关系不丢失 |
| 最大辅助字号 | 同一模拟器，Accessibility XXXL | 票面按内容与字号增长，可从票头滚动至票尾；两位序号、统计和存根保持可读 |
| 自动化 | iOS 26.5 模拟器 | 79 项 XCTest 全部通过；新增短票高度、88pt/104pt 阈值两侧、首尾不循环和 24% 阻尼断言；模拟器构建通过 |

取证完成后，主模拟器已恢复默认字号和关闭 Reduce Motion。

## 4. 证据边界

- 本批关闭短票空白尾、首张运行边界、未过阈值回弹和小票册减少动态效果的模拟器抽样；末张不循环已有策略断言，但未用 13 张小票形成完整原生录屏；
- 最大辅助字号截图证明对应票头与票尾状态，不替代中间全部内容逐项视觉检查；
- 窄屏短票、本机真实附件、实际导出/分享、VoiceOver、减少透明度、iOS 17–25 和真机手感仍未由本批关闭；
- 截图中的“优化后”只表示本批结果，不表示四页视觉或 V0.3 已由用户冻结。
