## 2. 共享合同

- 四页首屏可见内容从顶部栏下方 8pt 开始；
- 主内容与主纸张的水平外沿为 22pt；
- 叠纸层次使用 5pt/9pt 独立偏移，不通过增加容器 padding 缩窄最前纸张；
- 卡片、构思纸张和黑白热敏票据保留各自的边缘语义，不强行统一圆角或票齿。
