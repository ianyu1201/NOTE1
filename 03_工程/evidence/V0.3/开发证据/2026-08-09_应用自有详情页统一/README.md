# 应用自有详情页统一抽样

> 日期：2026-08-09
> 范围：NOTE1 自有对象详情、编辑、附件管理与概览排序页面；Quick Look、照片选择器、文件选择器和系统分享继续使用系统原生界面。

## 本批变更

- 灵感编辑、小票详情、附件管理、搜索构思集详情、历史灵感详情、构思历程详情、本机隐私说明和概览排序统一使用现役 56pt 顶部框架、48pt 命中区、46pt 可见玻璃按钮及独立居中标题。
- 保留各页面原有语义：返回、关闭、完成、添加附件、小票更多操作和编辑排序不互相替换。
- 小票详情的页内查找并入同一顶部容器；图标、输入文字和关闭操作按上下文标签规则限制到 1.25 倍，票面正文继续完整响应 Dynamic Type。
- 本机隐私说明移除与顶部重复的页内标题，并把过期的“V0.2 不提供”改为不随版本漂移的“NOTE1 不提供”。
- 新增嵌套页面可访问性隔离：详情或附件子页出现时，后方页面不再向 VoiceOver 暴露重复按钮；关闭后焦点树恢复。

## 运行与语义抽样

- 灵感编辑返回、底部完成和附件入口可达，自动保存路径未改变。
- 小票更多菜单仍包含模板、查找、继续构思、三种导出、分享、复制和删除；查找可打开、输入和关闭。
- 概览排序的“编辑”可进入重排状态并切换为“完成”，关闭后返回工作台。
- 历史详情打开时，可访问性树只保留当前详情的返回与对象动作；关闭后历史范围和条目恢复。
- 搜索构思集详情打开时，可访问性树只保留当前详情关闭动作。
- 工作台附件管理打开时，可访问性树只保留“完成”和“添加附件”；来源面板继续提供关闭、添加照片和添加文件。
