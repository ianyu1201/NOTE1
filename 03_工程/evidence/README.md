# NOTE1 证据索引

> 更新日期：2026-08-11

本目录保存运行截图、录屏、日志、语义快照、同视口对照板和开发参考图。证据只证明对应提交、设备、系统和操作范围内发生过什么，不自动定义产品需求，也不自动关闭 ISSUE。

## 目录职责

| 目录 | 内容 | 使用规则 |
| --- | --- | --- |
| `V0.1/历史演示/` | V0.1 历史真实运行截图 | 只说明历史运行事实，不作为 V0.3 视觉目标 |
| `V0.2/` | V0.2 模拟器、UI 审计与复验证据 | 按各批次索引理解；旧版、失败和“不采用”文件仍是历史证据 |
| `V0.3/确认视觉/` | 用户已选择的 V0.3 视觉方向与边界索引 | 表达目标，不证明代码已实现；按目录 README 区分吸收项与生成样例 |
| `V0.3/开发证据/` | V0.3 开发阶段的模拟器截图、录屏与对照证据 | 按批次 README 理解；不得作为最终独立验收通过结论 |
| `V0.3/MANIFEST.md` | V0.3 证据批次、提交与失效边界 | 新增、失效或重取证据时同步更新 |

V0.3 批次与 Git 提交的统一映射见 [`V0.3/MANIFEST.md`](./V0.3/MANIFEST.md)。历史开发截图在后续共享外壳、令牌或页面发生变化后，不自动继续作为最终候选证据。

## 证据等级

1. 产品确认视觉：由 `02_设计/NOTE1_产品设计与交互规格.md` 登记，表达目标，不证明已经实现。
2. 真实运行证据：本目录中的截图、视频和日志，表达对应构建的运行结果。
3. 外部或开发参考：只有在批次 README 或 `V0.3/确认视觉/README.md` 中登记来源、身份和适用边界后才可使用；不存在的通用 `references/` 不作为隐式入口。
4. 历史失败或否决证据：文件名或索引明确标注“旧版、失败、不采用”，不得作为当前通过结论。
5. 历史演示素材：`V0.1/历史演示/`，只作为 V0.1 运行事实参考。

## 使用门禁

- 引用证据时同时记录提交/build、设备、系统、步骤和未覆盖项；历史批次没有独立 build ID 时明确标记，不猜测。
- 模拟器截图不能替代真机、触觉、真实权限、VoiceOver 或最终分享投递。
- 目标图、候选图、运行图和推广图不得混写成同一证据等级。
- 风险项只有满足 V0.3 工程与运行验收基线中的关闭条件并经独立复验后才能标记关闭。
- 新证据先区分确认视觉、开发证据或最终验收，再进入对应版本和批次目录，并更新 README 或 manifest；不得把最终验收直接混入 `开发证据/`。

当前现役风险与证据要求见 [`03_工程/NOTE1_开发与运行验收基线.md`](../NOTE1_开发与运行验收基线.md)。
