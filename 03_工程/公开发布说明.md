# NOTE1 源码公开发布说明

日期：2026-10-09。公开仓库包含原生 iOS 实现与独立 Web 演示源码。本次上传包含已完成回归的修复，不表示 V0.4 已获得最终视觉、手感或独立版本批准。

## 源码与运行

- 原生：`ios/App/App.xcodeproj`，Scheme `App`，最低 iOS 17；本轮实际回归系统为 iOS 27.0。真机运行请在 Xcode 中选择自己的签名 Team。
- Web：`web/`；Node.js 22.13+、React、Vite。执行 `npm ci`、`npm run dev`，访问终端地址后打开应用。业务源码与原个人网站中的 NOTE1 演示逐字相同，新增宿主提供独立运行入口，不包含个人网站其他页面。
- 两端没有服务器、账号、云同步或静默数据上传。原生本机 JSON 与附件、Web IndexedDB 各自独立；备份格式不承诺跨端互导。
- 原生来源起点为 `62967c12752e93a96da306a40f1298380e22d366`，随后纳入小票空态辅助字号与备份类型声明两项修复。Web 的字节对应记录见 `web/源码对应清单.json`。
