# NOTE1 项目简报

> 更新日期：2026-08-14
> 作用：稳定描述项目定位和边界；产品细节以 V0.4 PRD 为唯一权威。

## 项目定位

NOTE1 是面向个人灵感记录与回看的原生 iPhone App，强调低压力、完全本机和“简单记，快速看”。用户能够离线完成记录灵感、卡片预览、归入构思集、结束本轮构思、生成并浏览构思小票的完整闭环。

## 平台与边界

- SwiftUI 原生 iPhone App，最低 iOS 17；
- 本机 JSON 与附件目录持久化；
- 无登录、后端、云同步、AI、任务管理、锁屏常显、小组件或 Live Activity；
- 正式代码只有 `NOTE1App → V02AppShellView → V02Store/V02DomainEngine` 一条活跃路径。

## S3 下游边界快照

- `frozen_constraints`：完全本机、SwiftUI 原生 iPhone、最低 iOS 17；V0.3 功能闭环非回归；四个等宽 Liquid Glass 一级入口及固定顺序；“梅墨雾白”“薄雾精密”“原位渐进”；小票生成/阅读合同；活动构思集和单组成员无固定数字上限；
- `allowed_changes`：在三份现役合同内实现四页 UI 与共享组件；以合同建议值作为起点调优卡片/构思动效；完成动态字体、VoiceOver、减少动态/透明度、增强对比度和系统材质降级；
- `prohibited_changes`：新增登录、同步、AI、任务管理等范围外能力；改变四入口数量、顺序、语义或 Liquid Glass 控制层；把纸张语言扩展为全 App 主题；复活 5/10 容量；新建平行 V0.4 PRD/设计/工程目录；把候选图或历史证据写成运行通过；
- `open_decisions`：实现后的动效手感及适配/无障碍实际体验是否通过用户验收；开发候选是否满足独立验收入口；
- `source_authority`：用户最新明确确认 → V0.4 PRD → V0.4 设计规格 → V0.4 工程基线 → 已接受 ADR；当前代码与运行证据只说明实现和观察事实。

## 当前完成标准

V0.4 只有在视觉与交互方向获用户确认、S3 UI 实现与运行验收合同冻结、实现候选完成约定验证且用户单独批准版本后，才能成为正式当前版本。V0.3 既有自动化和模拟器结果只作为功能非回归输入。
