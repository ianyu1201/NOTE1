# NOTE1 项目简报

> 更新日期：2026-08-11
> 作用：稳定描述项目定位和边界；产品细节仍以 V0.3 PRD 为唯一权威。

## 项目定位

NOTE1 是面向个人灵感记录与回看的原生 iPhone App，强调低压力、完全本机和“简单记，快速看”。用户能够离线完成记录灵感、卡片预览、归入构思集、结束本轮构思、生成并浏览构思小票的完整闭环。

## 平台与边界

- SwiftUI 原生 iPhone App，最低 iOS 17；
- 本机 JSON 与附件目录持久化；
- 无登录、后端、云同步、AI、任务管理、锁屏常显、小组件或 Live Activity；
- 正式代码只有 `NOTE1App → V02AppShellView → V02Store/V02DomainEngine` 一条活跃路径。
