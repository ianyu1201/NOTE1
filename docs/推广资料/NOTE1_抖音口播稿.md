大家好，今天给大家分享一下我自己用一天时间 Vibe Coding 的一款记录灵感的软件，它叫NOTE1。我自己出在高铁或者飞机的时候，经常会从脑子里会冒出很多想法。不知道你们都是用什么软件记录这些灵感的。我最开始是用的微信文件传输助手，后来用过 iphone 自带的备忘录和无边记。但是感觉每个都差点意思。最后我索性就自己开发了NOTE1。

NOTE1的使用方案很简单，录入完灵感之后点击右下角的按钮进入预览界面，可以像抖音一样上下滑动去预览，向左滑动完成灵感，下面的按钮滑动可以将灵感汇总到一个灵感组中。

我给 NOTE1 打的标签是快速录入，简单翻阅。灵感涌现的时候，可以快速记录，等到有空闲的时间，打开 NOTE1， 一条一条滑动之前写下的内容，让思绪回到当时，继续激发出新的灵感。
