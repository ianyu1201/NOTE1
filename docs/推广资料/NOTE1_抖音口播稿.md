# NOTE1 抖音口播稿

> 文档用途：抖音推广资料

哈喽大家好啊，我用 Codex 自己 Web Coding 了一款 iOS 软件，它叫 NOTE1。

它只做两件事：灵感来了，马上记下来；有空的时候，再像刷短视频一样一条条翻回去。

我经常在飞机和火车上突然有想法，以前不是丢进备忘录，就是发到微信文件传输助手，最后全混在一起。现在我先快速记录，回到酒店再上下滑动翻阅、点开继续写，或者整理成灵感组。

目前它只是用测试开发者身份运行在我自己的 iPhone 里。因为 iOS 开发者一年大约要 100 美元，我会先收集大家的反馈和功能需求，再根据需求量决定要不要上架 App Store。

这个项目纯公益，就是想和大家分享。你觉得还应该补什么功能，评论区告诉我。
