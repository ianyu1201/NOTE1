# NOTE1 V0.1 → V0.2 能力非回归矩阵

> 状态：V0.2 后续 UI 与交互开发的强制门禁  
> 建立日期：2026-08-02  
> V0.1 事实基线：`docs/01_产品/V0.1/NOTE1_PRD_V2.6.md`、V0.1 当前源码与 `media/demo/` 真实运行证据
> V0.2 产品基线：`docs/01_产品/V0.2/NOTE1_PRD_V0.2.md`
> 配套文件：`NOTE1_V0.2_UI二次优化手册.md`、`NOTE1_V0.2_UI问题清单_2026-08-02.md`

## 1. 目的

V0.2 可以改变信息架构、标准名词、数据模型和明确写入 PRD 的对象语义，但不能用“重新实现”覆盖 V0.1 已经确认且未被 V0.2 明确取消的基础能力。

本文件解决当前开发中的系统性问题：页面和数据骨架已经出现，但卡片反馈、专注编辑、附件闭环、位置恢复和按钮反馈等 V0.1 成熟能力被简化或遗漏。以后每一阶段除了证明“新功能存在”，还必须证明对应 V0.1 能力没有退化。

## 2. 判定规则

1. **明确改变**：V0.2 PRD 已写明改变对象、入口或状态语义，按 V0.2 实现；仍要保留 V0.1 已确认的直接操控、反馈、可取消和无障碍质量。
2. **继续保留**：V0.2 未取消的 V0.1 能力必须完整保留，不得用临时弹窗、静态列表或系统默认按钮降级。
3. **增强但不替代**：新增构思集、小票、声音资源或四一级页面时，只扩展原闭环，不得让文字、照片、PDF、文件预览或自动保存失效。
4. **运行证据优先**：构建成功、数据测试通过或页面能打开，不等于非回归通过。必须用相同视口的截图、原生录屏、可访问性快照和对象状态断言证明。
5. **待确认不等于可删除**：静态稿缺少非关键样式时可以使用克制临时样式；缺少既有能力时不得以“V0.2 尚未设计”作为删除理由。

### 4.4 独立灵感专注编辑

| 能力 | 强制要求 |
| --- | --- |
| 呈现层级 | 使用独立导航页面或等价全屏层级；支持系统式返回，不使用临时小弹窗替代 |
| 聚焦与保存 | 进入后自动聚焦；输入停止后自动保存；退出前刷新保存；不显示常驻保存状态 |
| 底部操作 | “添加附件”和“完成”在同一稳定操作行，键盘弹出后仍可用 |
| 附件新增 | 照片、文件和音频附件来源完整；导入失败不产生残缺资源 |
| 附件展示 | 显示名称、大小、类型或图片缩略图；音频可播放 |
| 附件预览 | 图片、PDF 和系统支持文件使用 Quick Look 或等价原生预览；不能只显示文件名 |
| 附件移除 | 可单独移除；不能把灵感变成文字与附件均为空；旧小票引用不被破坏 |
| 键盘 | 完成只保存并收起键盘，不执行“收起灵感”或“结束构思” |
| 返回 | 未完成输入不丢失；编辑返回后卡片位置保持 |

### 4.5 构思集工作台

V0.2 明确改变这一部分：进入构思集后直接原位编辑，不再为每一张组内卡片重复打开第二个专注编辑页面。但以下 V0.1 能力仍须保留：组内每条灵感独立、文字与附件可访问、修改自动保存、顺序可调整、移出后不丢内容、附件可播放/预览、返回前保存。

工作台成员卡片与卡片预览共用首屏尺寸规则：纸张从标题下方铺满到下方一级入口上沿，不使用独立固定短卡或卡片下方空白操作槽。

### 4.6 搜索、删除、回收站与备份

| 能力 | 非回归要求 |
| --- | --- |
| 搜索 | 命中文字、构思集名称和附件名；范围提示清楚；结果可回到真实对象 |
| 删除 | 只按 V0.2 定义删除最小对象；进入回收站；永久删除二次确认 |
| 回收站 | 30 天规则、恢复、永久删除和清空可用；恢复不会破坏仍有效附件 |
| 备份 | 覆盖 V0.2 全部对象、回收站和仍被引用附件；不生成缺附件的假成功备份 |
| 附件生命周期 | 灵感、小票或回收站仍引用时，底层文件不能删除 |

## 6. 关闭门禁

开发任务每次提交必须同时列出：

- 本次新增或改变的 V0.2 能力；
- 对应的 V0.1 非回归项；
- 自动化测试；
- 相同 iPhone 视口的前后截图；
- 需要跟手反馈的原生录屏；
- 尚未验证的真机、附件、无障碍和系统版本范围。

只报告“XCTest 全部通过、模拟器构建成功”不能关闭任何包含视觉、手势、附件或导航层级的非回归项。
