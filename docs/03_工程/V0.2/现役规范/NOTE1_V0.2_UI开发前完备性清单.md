> 文档状态：现役交接门禁

V0.2 UI 优化的高风险页面、核心手势、构思小票生成与小票册均已有确认视觉和证据要求，可以进入分批开发。PRE-06 属于阶段交付门禁，不阻塞开工；任何未被确认图覆盖的局部状态必须沿用共享组件或 V0.1 非回归基线，不得自由重设计。

## 5. 每个批次的强制验收门禁

1. **功能门禁**：相关单元测试/UI 测试和完整业务路径通过；
2. **视觉门禁**：目标图与实现图使用相同视口并排比较，记录尚存差异；
3. **交互门禁**：真实模拟器录屏包含开始、跟手、阈值、取消和完成；
4. **非回归门禁**：逐项回查能力非回归矩阵，不能用新页面覆盖旧闭环；
5. **状态门禁**：本文件对应状态矩阵至少有一份截图或录屏；
6. **无障碍门禁**：最大辅助字号、VoiceOver、Reduce Motion 与 Reduce Transparency；
7. **设备门禁**：模拟器通过后再做真机；iOS 26.5 结果不能替代 iOS 17–25 材质降级。

只有开发对话自查通过并给出证据后，才能交给用户测试。用户测试主要验证产品感觉、业务逻辑和隐蔽问题，不承担发现底栏遮挡、按钮点不到、页面缺失等基础缺陷。
