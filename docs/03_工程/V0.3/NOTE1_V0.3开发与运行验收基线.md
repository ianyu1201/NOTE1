## 2. 长期技术约束

### 2.1 ADR 约束

| ADR | 现役决定 | 变更规则 |
| --- | --- | --- |
| ADR-001 | 本机数据损坏时保护原数据，不用空状态覆盖 | 改变前新增取代 ADR |
| ADR-002 | Dynamic Type 与无障碍是产品基线 | 不允许以固定字号或裁切规避布局问题 |
| ADR-003 | 本机备份恢复与系统入口 | 恢复失败不得破坏当前有效数据 |
| ADR-004 | V0.2 单一活跃代码路径 | 不恢复 V0.1 双路径，不复制 V03 平行架构 |

### 2.2 数据与附件

- 领域状态修改必须通过 `V02Store` / `V02DomainEngine` 的有效操作；
- 容量、归属、结束、撤回、恢复和批量操作保持原子性；
- 小票快照冻结正文、成员顺序、附件元数据和过程事件；
- 灵感、小票或回收站仍引用资源时，底层文件不能删除；
- 文件导入失败、超限或目标对象不存在时回滚本次新增资源；
- 数据迁移或格式改变必须有向前迁移、失败保护和旧数据样本测试。

### 2.3 UI 与系统能力

- 使用现有 `DesignSystem.swift`、`DynamicTypeSupport.swift` 和共享交互策略，不在页面内复制主题常量；
- PhotosPicker、文件导入、Quick Look、系统分享和原生编辑菜单保留系统行为；
- 不用静态列表、功能缩水 Sheet 或自制预览替代已经存在的完整能力；
- 导航、对象身份和模态状态保持单一来源，避免多布尔状态组合出非法页面；
- 降级路径必须支持 iOS 17，不以当前最新模拟器专有材质作为唯一实现。

- [ ] 未确认内容标记为开放问题，不交给开发者自由补齐。

### 3.2 Git 与任务

- [ ] 固定完整 Git SHA、分支和干净工作树；
- [ ] 允许与禁止修改范围明确；

- [ ] 删除、重命名、迁移或范围变化已获得授权。

### 3.3 验证准备

- [ ] 相关测试在改动前可运行；
- [ ] 现状页面、数据样本和问题复现已记录；
- [ ] 数据迁移、附件和系统兼容影响已评估；

任一门禁不满足时，只允许补文档、原型、诊断或证据，不进入正式业务代码开发。

## 6. Given / When / Then / Evidence 运行合同

### AC-01 启动与四页导航

- **Given**：安装固定构建并存在默认或已有本机数据；
- **When**：在中文系统环境冷启动，依次点按并横滑进入四个一级页面，并打开原生文本编辑菜单；
- **Then**：显示正式 NOTE1 下划线启动标志；只出现一套 NOTE1 外壳，四页顺序固定，底部入口可点，页面内容不被底栏覆盖；四页左上均打开仅含回收站/设置的同一菜单，历史与搜索均常驻，搜索始终在最右、历史始终在其左侧；App 文案与复制/粘贴/选择等系统菜单符合中文环境；

### AC-02 记录与完整编辑

- **Given**：分别准备空草稿、长文字、照片、PDF、普通文件和音频样本；
- **When**：从灵感或卡片预览打开录入面板，保存并再次进入编辑；
- **Then**：空草稿不能保存，合法内容保存后出现在真实对象中；麦克风录制形成保留原录音的语音灵感，通过文件入口导入的音频只作为可播放附件；长文字、附件、键盘、自动保存、预览、播放、移除和返回均可用；
- **Evidence**：领域测试、默认/最大字号录屏、真实附件 Quick Look、文件系统检查。

### AC-03 卡片切换、收起与撤回

- **Given**：卡片流包含至少 3 张独立灵感；
- **When**：上下拖动未过/越过阈值，左右误触，左滑收起并在窗口内撤回；
- **Then**：卡片不铺满整页，有明确纸张边界、留白和前后叠层；方向锁定正确，未过阈值回弹，成功动作连续，首尾不循环，撤回恢复同一对象且不阻断继续操作；
- **Evidence**：策略测试、对象状态断言、默认/长内容/窄屏截图、完整原生录屏。

### AC-04 快速归入构思集

- **Given**：分别准备 0、1、5 个活动构思集，以及成员为 9/10 条的目标；
- **When**：点按或长按归入按钮，拖入两个操作目标、移出取消，并在后续面板选择；
- **Then**：中心按钮与卡片视觉一致，点按、长按、展开、高亮、取消和回收连续；两个目标始终显示；目标外松手不写入；5 个时新建提示容量；0 个时现有列表显示空态；满 10 条拒绝且不部分写入；
- **Evidence**：策略和领域测试、语义快照、完整原生录屏。

### AC-05 构思工作台与结束本轮

- **Given**：构思集包含多张长短内容和附件成员；
- **When**：切换、编辑、排序、移出、新增，随后发起结束并分别取消、确认和撤回；
- **Then**：编辑自动保存；键盘态不误切卡；取消不改变数据；确认只生成一票；撤回恢复轮次且不产生重复结束事件；
- **Evidence**：领域测试、键盘录屏、附件样本、轮次与小票状态断言。

### AC-06 小票册浏览与导出

- **Given**：至少 3 张不同长度、包含文字和照片/附件的小票；
- **When**：纵向阅读、左右换票、顶部下拉抽取、点按详情、切换模板并导出分享；
- **Then**：小票从纸张比例、纸色、边缘和排版层级上可识别为真实票据，不是普通白色长卡；左右换票连续跟手并表达前后票与票据夹的层次；方向不冲突，首尾不循环，详情内容与统计来自冻结快照；附件数量、最终文字数量和有效编辑次数在纸面或详情可见，轮次文案不由编辑次数伪造；模板推荐符合照片规则，导出文件可独立打开，系统分享拿到真实文件；
- **Evidence**：确认视觉对照、长/短/附件小票截图、完整换票手势录屏、模板/导出测试、PDF/Markdown 内容检查、真机分享录屏。

### AC-07 搜索、删除与回收站

- **Given**：正文、构思集、小票和附件名包含可区分关键词；
- **When**：在四个一级页面分别打开搜索；在灵感页长按一条灵感进入选择，按范围搜索，批量删除，恢复、永久删除和清空；

- **Evidence**：四页搜索导航断言、长按选择录屏与状态断言、搜索与批量测试、回收站 UI 录屏、文件检查。

### AC-08 备份、恢复与损坏保护

## 8. 开发与提交规则

1. 修改前核对 V0.3 PRD、设计规格、本文、适用 ADR、当前代码和测试；
2. 先记录现状与可复现步骤，再修改；
3. 以垂直切片提交，保持主路径可构建；
4. 先实现状态和数据正确性，再收口视觉与动效；
5. 不因技术便利改变产品结构、术语或对象语义；
6. 修改功能后至少运行相关测试和一次模拟器构建；
7. 涉及视觉、导航栏、手势反馈或样式时完成最小充分截图/录屏；
8. 不提交 DerivedData、`xcuserdata`、`.DS_Store`、临时截图或构建日志；
9. 报告实际完成的验证层级，模拟器通过不得写成真机通过；
10. 未覆盖项必须列出，不用“应该没问题”关闭。
