## 视觉资料

- `视觉基线/V0.2/`：已确认目标图与带职责范围的交互参考；
- `视觉候选/V0.2/`：尚待用户选择或需要修正的方案，不作为开发目标；
- `../开发文档/视觉参考/`：实现来源截图和小票动效参考；
- `../开发文档/验收证据/`：当前实现、反例、对照图和录屏，不作为产品目标。

## 更新规则

- 产品对象、状态、容量、页面层级或功能边界变化：更新 V0.2 PRD；
- 页面长相、组件、动效、手势或确认图变化：更新产品设计与交互规格；
- V0.1 成熟能力的保留标准变化：更新非回归矩阵；
- 当前代码缺陷和修复状态变化：更新 ISSUE；
- 尚未确认或不进入 V0.2：更新待讨论清单。
