# NOTE1 V0.2 待讨论清单

> 文档用途：集中记录尚需讨论、需要原型验证或明确延后的内容。
> 当前产品基线：`NOTE1_PRD_V0.2.md`。
> 规则：本清单不是开发需求，不覆盖 PRD 已确认行为；讨论形成决定后，必须先回写 PRD，再进入代码与测试。
> 更新日期：2026-08-01

## 1. 使用方法

- **开发中可调**：PRD 已有默认实现，可以先开发，再用真机、导出样本或用户反馈调整参数。
- **需要形成技术决策**：产品行为已经确认，但编码前需要 ADR、数据结构或失败处理方案。
- **后续版本候选**：V0.2 明确不开发，只保留讨论入口。
- 新讨论不得重新引入标签、任务压力、云端依赖或其他与“简单记，快速看”冲突的范围。

## 2. V0.2 开发中可调

### 2.1 左上角统一功能入口

当前默认包含“选择灵感 / 回收站 / 设置”，设置页内容已经固定为“本机备份与恢复 / 本机隐私说明 / 联系我 / 关于 NOTE1”。仍需通过页面原型确认：

- 入口图形采用 NOTE1 标识、菜单图标还是其他不冒充登录头像的符号；
- 使用左侧抽屉、浮层还是独立设置页面；
- 设置入口、分组和说明文字的具体视觉层级；
- 未来加入 Apple 登录或可选 AI 配置后，如何升级为用户入口而不改变当前导航习惯。

### 2.2 灵感页近期成果摘要

当前默认文案为“本周新增 N 条灵感 · 结束 M 轮构思 · 留下 K 张小票”，统计最近 7 个自然日。开发后继续观察：

- 三项数据同时存在时是否过长；
- 是否需要突出最近编辑的构思集，而不增加任务催促；
- 空状态和只有一项数据时的自然文案；
- 摘要的字号、位置和对时间流首屏的占比。

### 2.3 四个一级页面横滑

PRD 已确认支持横滑，同时采用对象手势优先。需要真机重点验证：

- 卡片预览左滑收起/结束与一级页面切换的边缘范围；
- 小票册左右换票与一级页面切换的边缘范围；
- 纵向列表、下拉抽取和斜向滑动的方向锁定；
- 键盘、搜索、批量选择、VoiceOver 和系统返回状态下是否暂停页面横滑；
- 小屏 iPhone、保护壳边缘操作和单手使用的命中率。

### 2.4 小票与卡片动效

参考方向已经确定，仍需通过独立原型和真机调整：

- 出票时长、纸张速度、停止收束和触觉时机；
- 左右换票的跟手比例、阻尼、景深和回弹；
- 下拉抽取阈值、夹口响应和后方小票补位；
- 卡片纵向切换、前后纸边露出和不同正文长度下的稳定性；
- “减弱动态效果”“降低透明度”和较大辅助字号下的替代呈现。

### 2.5 PDF 实际导出效果

首版按 A4 纵向和居中窄幅内容列开发。完成后使用真实样本检查：

- 纯文字长票、多照片胶卷票、语音、PDF 和混合附件；
- 卡片块、照片说明和时间路线的分页位置；
- 图片清晰度、文件体积、导出速度与内存峰值；
- 系统预览、存入“文件”、普通打印和分享给其他 App 的兼容性；
- 是否有必要在后续增加长页 PDF 或其他纸张预设。

### 2.6 批量操作细节

页面范围和默认动作已经确定，仍需用原型确认：

- “灵感”批量归入构思集时的目标选择、容量不足说明和原子失败反馈；
- 不同状态灵感混选时，“放回卡片流”是否隐藏不可用对象还是整体禁用；
- 多张小票导出和分享时的文件命名、顺序与系统分享体验；
- 构思集卡片概览是否在后续支持批量移出；
- 已结束构思集是否出现真实、低风险的批量管理需求。

### 2.7 回收站体验细节

30 天自动删除和恢复语义已经确定，仍需验证：

- 剩余天数与预计删除日期采用哪种显示更清楚；
- 批量恢复、永久删除和清空回收站的确认文案；
- 自动清理发生在启动、进入前台或打开回收站时的性能；
- 附件占用较大时是否在设置中显示本机空间提示；
- VoiceOver 是否能读出对象类型、删除日期和恢复结果。

### 2.8 搜索细节

搜索范围已经确定，仍需用真实数据调整：

- 中文关键词匹配、大小写、标点和空格处理；
- 结果摘要、命中词高亮和时间排序；
- “在小票中查找”的定位、上一处/下一处和无结果状态；
- 混合对象搜索切换筛选时的状态保持；
- 大量本机灵感、附件名称和小票快照下的性能。

### 2.9 双语音模式参数

语音灵感保存原始录音并可进行简体中文本机转写，音频附件保存用户导入的会议录音、音乐等文件；两者均可播放。以下参数不改变双模式语义，但必须在进入音频模块编码前确定默认值并通过真机验证：

- 语音灵感的单次最长录制时长、达到上限前的提示和自动停止行为；
- 音频附件的单文件大小上限，以及会议录音等较长文件超限时的反馈；
- 新录音的编码格式、采样参数、文件体积与清晰度平衡；
- 系统播放器实际支持的导入格式、无法播放格式的导入拦截；
- 录音中断、来电、切后台、空间不足和系统音频会话被占用时的保留与恢复；
- 播放控件在灵感时间流、卡片预览、编辑页、小票和 VoiceOver 下的紧凑呈现。

## 3. 编码前需要形成技术决策

以下不是新的产品讨论，但必须在相应模块编码前形成 ADR 或技术设计：

1. 灵感、构思集、构思轮次、构思小票快照和过程事件的数据结构。
2. 不可变附件资源、引用计数与安全垃圾清理策略。
3. 回收站删除时间、30 天自动清理、恢复和永久删除的幂等事务。
4. 结束本轮构思、生成一轮一票和约 2 秒撤回的原子事务。
5. V0.2 新数据版本的清库方式；V0.1 当前测试数据不迁移。
6. 批量归入、批量删除和批量恢复的全成或全不成规则。
7. PDF 渲染、分页、图片降采样与内存保护。
8. 页面横滑、对象手势和系统边缘返回的统一手势协调器或策略层。
9. 语音灵感临时录音、持久化音频资源、音频附件导入、本机转写、权限矩阵和音频会话中断的统一技术设计。

## 4. 后续版本候选

### 4.1 可选 AI 整理

- 候选为用户自带 DeepSeek API Key；
- 只分析用户明确选择的当前构思集或小票，不默认建立全库 RAG；
- AI 结果作为独立草稿，不覆盖灵感和固定小票；
- 需要继续讨论隐私提示、费用、失败处理和非技术用户门槛。

### 4.2 Apple 登录与未来账号入口

- 当前仍是完全本机、无登录 App；
- 后续可以评估 Apple 登录、设备身份和账号设置；
- 登录不自动等于云同步，数据位置、恢复和隐私必须另行确认；
- 左上角统一功能入口为未来账号能力保留信息架构空间，但 V0.2 不显示占位功能。

### 4.3 更多小票模板与实体打印

- V0.2 只有经典票和胶卷票，不提供深度 DIY；
- 后续根据真实内容评估更多一键模板；
- 热敏机、蓝牙、ESC/POS 和实体打印属于更后版本，不影响当前 App 与 A4 PDF。

### 4.4 产品验证与用户研究

- 艺术、设计、摄影用户使用胶卷票时的照片数量与清晰度需求；
- 用户是否能理解“构思集 / 构思轮次 / 构思小票”的关系；
- 5 个构思集、每组 10 条灵感是否保持足够边界又不过度限制；
- 卡片流和小票册是否真正形成 NOTE1 的产品辨识度；
- 30 天回收站是否符合本机存储和误删恢复的真实需求。

## 5. 讨论完成后的回写规则

每项讨论形成结果后执行：

1. 将确认结论写入 `NOTE1_PRD_V0.2.md` 对应功能章节和验收口径；
2. 若改变数据、存储或跨模块关系，新增或取代对应 ADR；
3. 更新自动化测试与真机验收清单；
4. 从本清单删除已经关闭的选择题，或标记其已关闭并链接到 PRD；
5. 不以本清单中的候选描述直接修改生产代码。
