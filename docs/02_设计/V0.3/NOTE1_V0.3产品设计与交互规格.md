> 文档状态：V0.3 唯一现役设计基线，当前处于 defining，尚未冻结最终视觉
> 更新日期：2026-08-11

## 0. 文档职责

本文定义 NOTE1 当前页面结构、视觉语言、组件、状态、手势、动效、适配和无障碍要求。产品对象和业务边界以 V0.3 PRD 为准；实现与证据要求以 V0.3 工程与运行验收基线为准。

当前代码与模拟器运行态是 V0.3 设计优化的现状起点。代码中已经形成且与 PRD 一致的页面结构在本文保留；用户明确提出的优化目标写入本文后高于现状实现。历史候选图、旧截图和外部参考不参与裁决。

## 1. 设计目标与视觉身份

### 1.1 目标

NOTE1 应呈现安静、轻盈、清楚、有触感的本机记录工具。用户第一眼看到内容和当前动作，而不是管理系统、表单或工具栏。

### 1.2 当前视觉身份

- 冷调淡紫背景作为全局画布；
- 深海军蓝用于正文、图标和当前选中状态；
- 浅亮玻璃用于导航、菜单和轻量浮层；
- 纸张用于灵感卡片和构思工作台；构思小票使用独立的黑白热敏票据语言；
- 默认状态不发灰，不使用刺眼纯白或默认系统蓝大按钮；
- 阴影只表达纸张层级，不制造厚重悬浮白块；
- 使用系统语义字体和 Dynamic Type，不引入装饰性字体。

该身份已确认为当前 V0.3 实施方向，但不能停留在通用 SwiftUI 组件拼接。顶部框架、纸张边界、按钮材质、图标粗细、排版节奏与动效收束必须形成贯穿四页、可被一眼识别的 NOTE1 视觉与交互身份。最终确认图仍需用户对四页总览和关键状态统一确认。

### 1.3 语义颜色

| 语义 | 当前基线 | 用途 |
| --- | --- | --- |
| `noteInk` | 深海军蓝，约 `#071B34` | 主标题、正文、关键图标、选中态 |
| `noteSecondaryInk` | 深蓝灰；在当前最深画布上的计算对比度不低于 `4.5:1` | 时间、说明、不可用状态 |
| `noteCanvasTop` | 极浅冷白紫，约 `#F7F7FF` | 背景上端 |
| `noteCanvasBottom` | 淡紫，约 `#EBECFF` | 背景下端 |
| `notePaper` | 带轻微紫调的纸白 | 灵感纸张与卡片 |
| `receiptPaper` | 中性近白，不带黄色或复古暖调 | 构思小票纸面 |
| `receiptInk` | 黑色或石墨黑 | 构思小票票头、正文、统计和分隔线 |
| `noteGlass` | 半透明浅亮玻璃 | 顶部按钮、导航、录入工具栏 |
| `noteSelected` | `noteInk` | 当前一级入口和明确主操作 |
| `noteDanger` | 受控系统红 | 永久删除与破坏性确认 |

- 纯白只作为纸张高光，不铺满导航、按钮和大面积内容区；
- 不允许系统 tint 漂移成亮青蓝；
- 颜色必须通过现役代码变量实现，表中十六进制仅用于识别与对照，不鼓励页面内硬编码。

### 1.4 尺寸、间距与命中

- 基准视口为约 393×852 的主流 Pro 尺寸，同时在约 368×800 的窄视口复验；
- 四个一级页共用同一顶部组件：高度 56pt、水平安全边距 22pt，中间统一显示 `NOTE1`；
- 顶部圆形按钮实际命中区为 48×48pt，可见材质直径 46pt，同侧按钮间距 4pt，四页使用同一阴影与按压反馈；
- 灵感与小票册的中间标题保留页内菜单能力，但指示符独立于 120pt 标题容器布局，不得将 `NOTE1` 推离屏幕中心；
- 所有交互目标不得小于 44×44pt，Dynamic Type 放大时优先增加容器高度；
- 页面水平安全边距使用共享变量，标题、纸张和底栏不得各自漂移；
- 四个一级页的首屏可见内容统一从顶部栏下方 8pt 开始，主内容或主纸张水平外沿为 22pt；
- 需要表达叠纸时，后层只用 5pt/9pt 偏移露出，不得通过增加容器水平 padding 缩窄最前纸张；
- 同级内容遵循约 8pt 节奏，页面分区使用约 16/24pt 节奏；
- 不为对齐单张截图散落互不关联的固定 padding 或固定高度。

### 1.5 Mononote 参考边界

2026-08-09 根据 [Mononote: One Note 官方 App Store 页面](https://apps.apple.com/us/app/mononote-one-note/id6788222857) 与官方截图，当前参考方向包含：

- 打开后立即呈现当前主要对象，不先展示管理面板；
- 一个屏幕只有一个最明确的主操作，次级能力收入克制的入口；
- 大留白、简洁字号层级、大命中区和明确的按压状态，降低认知负担；
- 完成主要操作后结果立即明确，不让用户猜测是否已保存。

Mononote 只作为上述极简设计方法参考；NOTE1 维持四页结构和现有启动入口，不照搬单条笔记模型、启动即编辑、底部中心 Done、锁屏常显、小组件或 Live Activity。

## 2. 全局页面框架

### 2.1 一级页面

固定顺序：

`灵感｜卡片预览｜构思集｜小票册`

- 四个入口等宽，命中高度不低于 44pt；
- 选中项使用深蓝强调，未选中项使用蓝灰线性图标；
- 底部导航保持稳定，不随页面内容跳动；
- 页面内容通过安全区为导航留出空间，不用额外大块空白避让；
- 点击底部入口始终是可见、等价的兜底路径。

### 2.2 浮动新增按钮

- 显示页面：灵感、卡片预览、构思集；
- 隐藏页面：小票册；
- 三页使用同一右下位置、光学尺寸、材质和按压反馈；
- 分别执行“记录灵感”“新增卡片”“新建构思集”；
- 覆盖在内容层之上，只避开底部导航、Home Indicator、键盘和安全区；
- 不为按钮预留独立槽位、固定空白行或大块空白；
- 搜索、选择、录入、附件选择、详情和键盘编辑状态下隐藏。

### 2.3 顶部框架

- 四个一级页面使用同一套顶部槽位：左上全局菜单、中间页面标题、右上次级入口与最右搜索；
- 四页中间标题文案均为 `NOTE1`，不再分别显示“构思集”或“小票册”；
- 左上全局菜单在灵感、卡片预览、构思集和小票册展开后均只显示“回收站”与“设置”，顺序、图标和文案完全一致；
- 搜索按钮在四页始终占用最右槽位，不因历史或更多按钮出现而换位；
- 历史按钮在四页始终常驻并紧贴排在搜索左侧；四个按钮的图标、文案、命中区和可访问名称一致，均打开同一全局历史中心；
- 灵感页 `NOTE1` 保留排序入口，小票册 `NOTE1` 保留模板/导出等页内菜单；卡片预览与构思集使用静态 `NOTE1`；
- 页面级的模板、导出、分享和删除等操作不占用最右搜索槽位，收入对象或页面内的次级菜单；
- 同类按钮跨页面保持尺寸、材质、图标粗细和按压反馈一致。
- 搜索、历史、回收站、设置使用同一二级页面顶部几何：56pt 高度、22pt 水平边距、48pt 命中区和 46pt 可见玻璃按钮；标题独立居中，不因左右动作数量不同而偏移。
- 二级页只统一框架，不抹平语义：搜索保留取消/选择，历史保留返回，回收站与设置保留关闭，回收站更多仍位于右侧。
- 记录灵感与构思工作台等对象页沿用同一 56/48/46pt 顶部几何和同源玻璃按钮，但保留对象名称与容量等上下文，不改成 `NOTE1` 品牌标题。
- 构思工作台即使左侧只有返回、右侧同时存在结束与更多，也必须按屏幕中心放置集合名和 `N/10 条灵感`，不得按左右动作剩余空间做视觉居中。
- 记录页的取消、有未保存内容时的放弃确认与明确保存保持可达；工作台返回前持久化当前编辑，结束仍先确认，更多菜单保持概览与排序、改名和删除构思集。
- 保存及工作台底部附件、移出、更多属于上下文操作标签，最大辅助字号限制到 1.25 倍并保留至少 44pt 命中；灵感正文和编辑内容不使用该上限，继续完整响应 Dynamic Type。
- 灵感编辑、小票详情、附件管理、搜索构思集详情、历史详情、本机隐私说明和概览排序均属于 NOTE1 自有详情页，继续使用共享 56/48/46pt 顶部框架；同一语义使用同一图标、尺寸、材质和按压反馈。
- 自有详情页只统一表现，不抹平动作：全屏编辑与历史详情使用返回，独立模态详情使用关闭，附件管理保留完成与添加，概览排序保留关闭与编辑/完成，小票详情保留返回与更多。
- 小票页内查找与其他上下文操作条的图标、输入和关闭文案最大 1.25 倍；票面、灵感正文、隐私正文和详情内容继续完整响应 Dynamic Type。
- 嵌套详情、附件预览或导出层出现时，后方页面及其顶部按钮必须退出可访问性焦点树，关闭后恢复；Quick Look、照片/文件选择器和系统分享属于系统界面，不套用 NOTE1 自有顶部。

### 2.4 页面横滑

- 四页按固定顺序切换，首尾不循环；
- 灵感和构思集总页在未命中内容控件时可整页横滑；
- 卡片预览和小票册只从保留边缘发起一级页切换，对象手势优先；
- 手势方向和距离明确后才接管页面切换；
- 未过阈值回弹，不出现半页停留或误触发对象操作。

## 3. 通用组件与反馈

### 3.1 纸张与玻璃

- 纸张层承载正文、图片和附件摘要；
- 玻璃层承载导航、菜单、临时提示和操作面板；
- 减少透明度开启后使用不透明浅色表面和清晰边界；
- iOS 17–25 不支持较新材质时，降级到系统可用材质，不改变层级、可读性和命中区域。

### 3.2 按钮

- 默认态保持清楚和浅亮；
- 按下只做轻微缩放、降亮或材质密度变化，不弹跳；
- 破坏性操作使用红色语义色，并在执行前确认；
- 图标按钮必须提供可访问名称；仅靠手势可达的能力必须有点按或 VoiceOver 等价入口。

### 3.3 临时反馈

- 收起、结束撤回、容量限制和保存失败采用不阻断主路径的短时反馈；
- 提示与触发对象保持空间关联，不固定占据内容区域；
- 错误发生后保留当前内容、选择和操作上下文，不误关闭面板。

## 4. 分页面规格

### 4.1 灵感页

#### 结构

1. 稳定顶部栏；
2. 按日期分组的灵感时间流；
3. 右下浮动新增按钮；
4. 底部四入口导航。

#### 内容层级

- NOTE1 品牌可识别，但不压缩内容阅读空间；
- 正文高于时间、归属和附件元数据；
- 灵感条目避免连续厚重白卡，使用留白、分组和轻量表面建立层级；
- 最后一条内容滚动后可完整阅读和点击，不被底部导航或浮动按钮覆盖。
- 长按任一灵感进入批量选择态，并默认选中该条；左上全局菜单不再出现“选择”。

#### 录入与编辑

- 点按“+”后从底部出现录入面板；
- 多行文字区可随内容增长，长内容内部滚动并保持光标可见；
- 工具行保留现有三类入口：附件、麦克风和保存；附件入口再区分照片与文件，音频附件由文件选择器导入，不增加独立的音频按钮；
- 语音灵感录制时可显示本机简体中文转写；转写不可用或中断时明确提示“录音仍会保留”，不阻断保存和播放；
- 键盘出现后保存、附件和关闭入口仍可达；
- 新建灵感必须明确点按“保存”才落盘；已有灵感自动保存，点按“完成”退出；
- 支持交互式收起键盘和明确的键盘工具栏操作；
- 点按已有灵感进入完整编辑页，不使用功能缩水的临时小弹窗；
- 默认字号自动聚焦；最大辅助字号不自动拉起键盘。

### 4.2 卡片预览

#### 结构

- 当前卡与屏幕左右及上下框架保留明确呼吸空间，不再铺满整个页面；
- 卡片有可识别的纸张边界、轻阴影和克制圆角；背后前后卡片露出足以识别的纸边与位移，建立卡片堆深度；
- 页码和“归入构思集”按钮叠加在当前卡片底部；
- 不在卡片与底部导航之间增加独立操作槽；
- 卡片包含正文和附件分类摘要，点按进入完整编辑。

#### 上下切卡

- 当前卡跟手移动，下一张或上一张同步承接；
- 明确纵向意图后锁定纵轴；
- 未过阈值回弹，过阈值连续完成切换；
- 首尾不循环，边界有克制阻尼；
- 切换后当前对象身份稳定，不跳回首卡。

#### 左滑收起

- 只接受非系统返回边缘开始的明确左滑；
- 接近阈值后低饱和“收起”背景和文案渐显；
- 未过阈值回弹，过阈值当前卡连续离场，下一卡承接；
- 收起后显示短时“已收起 / 撤回”；
- 撤回不阻断继续切卡、点开或收起下一张。

#### 快速归入构思集

- 一个圆形按钮悬浮在当前卡片底部，按钮使用与当前纸张一致的颜色、材质、边界和阴影；
- 点按时按钮轻微缩放并恢复，操作面板从按钮所在位置连续展开；长按达到阈值时表达“已接管拖拽”的视觉反馈；
- 长按后固定同时显示两个较大的拓展目标：“新建构思集”和“归入现有构思集”；
- “新建构思集”位于左上并轻微逆时针倾斜；“归入现有构思集”位于右上并轻微顺时针倾斜；
- 不使用弧线、虚线、箭头或 `3×2` 管理宫格；
- 手指移入真实目标后高亮，移出立即取消高亮，目标外松手取消；
- 成功时目标轻微收合至结果方向，取消时两目标连续回收到中心按钮；不得直接消失或瞬移；
- “减少动态效果”开启时可缩短距离和时长，但仍保留按压、展开、选中与取消状态。
- 松手只选择操作类型，随后打开新建面板或现有构思集列表；
- 两个目标始终存在。5 个构思集时后续提示新建容量；0 个构思集时现有列表显示空态；
- 点按和 VoiceOver 自定义操作提供等价入口。

### 4.3 构思集总页

- 只展示构思中的构思集，不混入已结束内容；
- 标题居中，右下使用共享浮动“+”；
- 空态仍显示“+”；达到 5 个时按钮仍显示，点按后在页面下方短时提示容量限制；
- 点按构思集直接进入工作台，不先进入 CRUD 管理页；
- 构思集使用轻量纸张或堆叠语言，不使用大面积管理表单；
- 构思历程独立展示已结束构思集和历次轮次，不与小票册重复同一列表。

### 4.4 构思集工作台

- 延续卡片预览的纸张和纵向叠卡语言；
- 进入即原位编辑，不为每张成员卡重复打开第二个专注编辑页；
- 支持最多 10 张成员卡片切换、文字编辑、附件访问、排序、移出和新增；
- 文字、附件和修改自动保存；
- 非键盘态右下浮动“+”新增组内灵感；键盘态隐藏；
- 键盘出现后纵向手势用于滚动正文，暂停纵向切卡；
- 键盘工具栏提供前后卡片和完成编辑等价操作；
- 结束本轮构思是构思集级动作，组内单卡左滑不能结束整轮；
- 页面级主要动作与低频管理动作分层，不能在底部堆叠过多控件。

### 4.5 结束本轮与小票生成

- 构思集左滑只在明确构思集级入口或区域中生效；
- 越过阈值后先进入确认，不直接改写数据；
- 确认页展示构思集名称、成员数量和结果说明；
- 取消返回原工作台，成员、顺序和内容不变；
- 确认后纸张生成分为准备、出纸、内容显现和完成四个可理解阶段；
- 生成期间底部一级导航保持可见且不误触；
- 生成完成后短时提供撤回；
- 减少动态效果开启后缩短位移和时长，但保留生成结果和对象关系。

### 4.6 小票册

- 唯一现役视觉参考：[NOTE1_V0.3_小票黑白热敏票据参考.png](../../../evidence/V0.3/确认视觉/NOTE1_V0.3_小票黑白热敏票据参考.png)，首次确认日期 2026-08-09，并于 2026-08-11 以完全相同附件再次确认；该图高于此前所有小票候选图、暖黄实现和旧开发参考；
- 页面以票据夹、当前长票和后方纸边构成单焦点画面；
- 不使用普通列表、网格、瀑布流或短摘要卡；
- 纸张使用中性冷白或近白，打印内容使用黑色/石墨黑；明确禁止黄色、牛皮纸色、复古暖色和与黑白票据冲突的彩色装饰；

- 真实感不等于堆叠污渍、大面积纹理、伪立体齿孔或影响阅读的装饰；最终纸张观感需通过视觉方案确认；
