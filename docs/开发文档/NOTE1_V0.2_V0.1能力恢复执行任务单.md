## 1. 执行原则

本任务不是“根据截图修三处样式”，而是一次 V0.1 → V0.2 的系统性能力恢复。

1. V0.2 可以改变对象名称、数据模型、一级页面和明确写入 PRD 的流程，但不得删除 V0.1 已确认且未被 V0.2 明确取消的能力。
2. 禁止用简化 Sheet、静态占位、系统默认按钮或只读附件行替代 V0.1 的完整交互。
3. 先恢复基础能力，再继续小票册视觉。P0-C 小票册最终实现必须排在本任务之后。
4. 每个检查点需要连续完成“实现 → 测试 → 构建 → 模拟器运行证据 → 提交”，不能在“已准备、下一步将执行”处结束。
5. 工具无法自动化的真实手指轨迹必须如实列为人工复验，不得把策略测试或截图冒充手感通过。

## 4. 检查点 BR1：卡片预览完整收口

### 4.1 必须实现

1. 独立灵感仅左滑有效；普通上下切换不得误触收起。
2. 左滑接近阈值后，背景逐步显示低饱和“收起”反馈；未越过阈值回弹。
3. 越过阈值后卡片连续离场，离场完成后再写入 `tuckedAway`。
4. 底部短时显示“已收起 / 撤回”，撤回条不能阻止用户继续上下切卡或继续收起下一张。
5. 编辑返回、一级页面切换和 App 重启后，优先回到仍存在的同一张卡片；对象不存在时安全落到相邻卡片。
6. “归入构思集”按钮位于卡片和底部一级导航之间的稳定操作槽；不得悬在画面中部，也不得与右下浮动“+”或 Home Indicator 冲突。
7. 点按构思集按钮打开 3×2 托盘；按住上拖时按钮本体不跟随手指。
8. 释放时只按最终位置判断：目标内归入；空白取消；离开目标后不得沿用旧高亮。
9. 普通灵感卡片显示文字与附件摘要；照片、PDF/文件、音频不能在卡片层完全消失。

## 5. 检查点 BR2：完整专注编辑与附件闭环

### 5.1 页面层级

1. 点按普通灵感卡片进入独立、全屏的专注编辑层级，不使用当前功能缩水的 `.sheet(item:)`。
2. 返回采用 iOS 原生导航关系并支持左边缘返回；返回后卡片位置不变。
3. 编辑页不显示“已保存”常驻文案，不使用顶部“取消 / 保存”作为唯一保存路径。
4. 仅把 `.sheet(item:)` 改名为 `.fullScreenCover(item:)` 不能自动视为关闭回归；若没有系统式返回关系、左边缘返回和正确的页面转场，仍须改为导航 push 或提供等价且经过运行验收的全屏层级。

### 5.2 文字保存

1. 进入页面约 0.3 秒后自动聚焦正文。
2. 停止输入约 450ms 自动保存。
3. 页面退出前取消待执行任务并再次同步保存。
4. 保存失败使用现有中文错误反馈，不能静默丢字。
5. “完成”只保存并收起键盘，不执行“收起灵感”或“结束本轮构思”。
6. 必须保留 `savedText` 或等价已保存快照；文字未变化时不得重复写入、重复增加“有效编辑”事件或持续触发磁盘保存。

### 5.3 附件闭环

1. 底部同一行保留“添加附件”和“完成”，键盘弹出后仍处于可达位置。
2. “添加附件”提供照片和文件两个来源；音频附件沿用 V0.2 已确认入口，不得覆盖前两者。
3. 照片支持多选，导入失败不产生残缺资源。
4. PDF、普通文件和图片支持原生 Quick Look 或等价系统预览；音频可播放。
5. 附件行显示名称、大小与类型；图片应显示真实缩略图，不能只用通用 `photo` 图标代替。
6. 单个附件可移除；文字与附件不能同时为空。
7. 原灵感移除附件后，如果旧构思小票或回收站仍引用，底层资源继续保留。
8. 新附件必须先安全写入资源文件，再原子关联到灵感；关联失败时回滚未引用资源。

### 5.4 代码参照

必须以 V0.1 完整实现为结构来源：

- `ios/App/App/EditorView.swift`：全屏编辑、自动聚焦、450ms 自动保存、底部操作、附件移除。
- `ios/App/App/AttachmentViews.swift`：附件来源面板与 Quick Look。
- `ios/App/App/AttachmentImporter.swift`：照片/文件转换与大小校验。
- `ios/App/App/V02Store.swift`：V0.2 不可变资源、引用与垃圾清理。
- `ios/App/App/V02AppShellView.swift` 中 `V02InspirationEditorView`：需要替换的简化实现。

禁止直接让 V0.1 `NoteStore` 管理 V0.2 数据。应复用视图结构与交互，将存储调用适配到 `V02Store`。

### 5.5 必补数据接口与测试

若当前 `V02Store` 缺少“把新资源关联到既有灵感”的原子接口，应补充正式接口并测试：

- 成功写入资源并关联灵感；
- 关联失败时不遗留孤儿文件或孤儿元数据；
- 超限文件不写入；
- 移除最后一项时遵循非空约束；
- 旧小票或回收站引用存在时不删除底层文件；
- 最后一个引用释放后才安全清理。

### 5.6 运行验收样本

至少准备并运行：

1. 长中文正文，验证光标、自动保存和返回。
2. 单张照片与多张照片。
3. PDF，点按后进入 Quick Look。
4. 普通文件，显示文件名与大小并可预览。
5. 音频附件，可播放。
6. 删除原灵感附件后打开旧小票，快照附件仍可访问。
