## 5. 实施顺序

### P0-C1：静态构图先通过

先创建小而独立的原生组件，命名可以调整但职责必须分离：

- `V02TicketClip`：票据夹、固定出纸口和空间锚点。
- `V02ReceiptPaper`：经典票、胶卷票共用的纸张轮廓和信息骨架。
- `V02ReceiptDeck`：当前票、后方 1–2 层纸边、索引和层级。
- `V02ReceiptBookView`：小票册根页面的空态、单票、多票、搜索与选择模式编排。

静态状态至少覆盖：

1. 空态。
2. 单张经典票。
3. 三张混合小票的叠层状态。
4. 胶卷票含真实照片缩略图的状态。
5. 选择模式。
6. 默认字号和最大辅助字号。

静态阶段必须做到：

- 页面只有一个主对象：夹中的当前小票。
- 后方小票只露纸边和轻微层级，不透出可读正文。
- 票面至少显示构思集名、轮次时间、灵感数量、简短过程摘要和模板特征。
- 纸张具有统一的小票轮廓、齿边或票孔语义，不能只是普通圆角白卡。
- 小票册底部图标使用与确认稿一致的锯齿小票语义；不得以临时 `ticket` SF Symbol 作为最终视觉。
- 删除“上一张 / 下一张”两个大灰按钮；页码只作为次级反馈。
- 导出、分享和删除不在当前票主体常驻一排胶囊。
- 浮动新增按钮不得遮挡小票册入口；底栏不得发灰。

完成静态构图后，先生成同视口对照板并修正差异。静态检查点未通过，不进入动效。

### P0-C2：左右换票与向下抽取

使用单一活动轴和归一化进度管理手势：

- 水平锁定后，当前票、目标票、后方纸边同步跟手。
- 未过阈值回弹，过阈值吸附到相邻票；首尾不循环。
- 向下锁定后，当前票从夹口连续抽出，后方纸张同步补位。
- 未过阈值回到夹内，过阈值连续进入详情；不能松手后突然跳页。
- 斜向短滑不提交动作。
- 当前票上的对象手势优先于一级页面横滑；只有 PRD 规定的屏幕边缘区域切换一级页面。
- 点按当前票和 VoiceOver 自定义操作提供等价详情入口。

### P0-C3：结束本轮构思后的出票动画

固定顺序：

1. 用户确认结束本轮构思。
2. `endRound` 原子保存轮次和不可变小票快照；保存失败不播放成功动画。
3. 票据夹出现短促准备反馈。
4. 小票从固定夹口连续送出，内容随纸张进度显现。
5. 到达展示位置后减速停止，触发一次轻触觉。
6. 稳定后可查看本票、返回或进入小票册。

同一次结束动作只能生成一张小票。约 2 秒撤回仍可用，撤回成功后刚生成的小票和已结束轮次同步恢复，不能留下孤儿票。

开启“减弱动态效果”时，改为短距离展开和淡入，但仍清楚表达“生成并留下了一张小票”。

### P0-C4：小票详情与模板

- 保留经典票和胶卷票两个模板；模板只改变展示排版，不改变不可变快照。
- 图片使用真实缩略图；音频可播放；PDF 和一般文件显示文件名、类型、大小与可预览入口。
- 长票在详情中滚动，不在根页面展示完整长条缩略图。
- `在小票中查找`、继续构思、导出、分享、删除放在详情的次级操作中。
- 保留 PDF / Markdown / 纯文本导出以及批量导出、分享和删除。

## 6. 必须保持的非回归能力

1. 一轮严格生成一张小票，重启后仍可读取。
2. 小票是固定快照；之后编辑或删除原灵感不改变旧票。
3. 删除小票不影响来源构思集和灵感；回收站可恢复。
4. 附件资源按灵感、小票和回收站引用安全清理。
5. 构思集结束后约 2 秒撤回有效。
6. 搜索可找到小票；小票册批量导出、分享、删除仍可用。
7. 四个一级入口和整页横滑保持可达，新增按钮不遮挡底栏。
8. iOS 17–25 材质降级、Reduce Motion、Reduce Transparency、Dynamic Type 和 VoiceOver 有等价路径。

## 7. 自动化测试

至少新增或更新：

- 水平 / 向下方向锁定策略、阈值、首尾和取消路径的纯逻辑测试。
- 结束本轮成功后只生成一票；重复调用不生成第二票。
- 出票展示状态不参与数据写入，动画中断不产生重复票。
- 撤回结束本轮后轮次、小票和成员状态一致恢复。
- 模板推荐和用户切换只影响展示。
- 小票删除、恢复、永久删除与附件引用生命周期。
- Accessibility identifier 覆盖当前票、抽取详情、搜索、选择和模板切换。

阶段结束必须运行全部 XCTest 和一次模拟器构建；警告与未验证项单独列出，不得隐瞒。

## 9. 直接否决条件

- 仍是普通白卡、列表、网格、瀑布流或通用横向卡片轮播。
- 仍把临时 SF Symbol 当最终小票册图标。
- 仍出现大灰“上一张 / 下一张”按钮或常驻“导出与分享”胶囊。
- 相邻票正文可读、票据层级不清楚或纸张不像同一本小票册。
- 松手后才突然换票、抽取或跳详情，没有连续跟手过程。
- 出票动画先于数据成功，或一次动作产生重复小票。
- 底栏发灰、系统蓝、浮动新增按钮覆盖小票册入口。
- 只报告构建、单元测试或静态截图，没有对照板和原生录屏。
- 为完成小票册破坏已经关闭的 BR1、BR2、BR3 非回归能力。
