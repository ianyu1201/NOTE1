## 1. 产品定义

NOTE1 是一个低压力、完全在本机运行的原生 iPhone 灵感记录 App。它帮助用户快速留下零散内容，在卡片流中重新遇见灵感，把相关灵感放入构思集，并在结束一轮构思时生成固定的小票成果。

### 1.1 用户结果

用户无需学习复杂方法即可：

1. 记录文字、照片、文件或声音；
2. 在卡片预览中重新遇见灵感；
3. 将不再需要继续翻阅的灵感收起，或归入构思集；
4. 在构思集中集中编辑、补充、排序和结束一轮构思；
5. 在小票册浏览、导出、分享或基于历史成果继续构思。

### 1.2 产品原则

- 本机优先：无账号、无后端、无云同步，核心闭环离线可用。
- 低压力：不显示连续天数、排名、完成率或催促性指标。
- 内容优先：容器、按钮和动效服务于内容，不制造任务管理感。
- 直接操控：主要对象可通过点按和手势直接操作，并提供等价无障碍入口。
- 结果可信：小票是结束时的固定快照，后续编辑不能改写历史成果。

## 2. 用户与使用场景

### 2.1 主要用户

希望随手记录、需要保留思考过程，但不愿维护复杂分类体系的个人用户。

### 2.2 主要场景

- 突然想到一句话、一个方向或一段未成形内容时快速记录；
- 稍后通过卡片重新遇见内容，而不是依赖主动搜索；
- 将数条相关灵感集中到一个构思集继续推敲；
- 一轮构思结束后保留可回看的小票；
- 搜索、恢复、备份或导出本机资料。

## 3. 产品边界

### 3.1 平台与数据

- 原生 SwiftUI iPhone App，最低 iOS 17。
- 数据保存在 Application Support 下的本机 JSON 和附件目录。
- 没有登录、账号、后端、云同步、跨设备协作或 Web 管理端。

### 3.2 明确不做

- AI 生成、总结、推荐或自动分类；
- OCR、语义搜索、RAG 或相似灵感推荐；
- 任务管理、待办、提醒、打卡、完成率或生产力排名；
- 社交关注、公开社区、团队协作；
- 订阅、会员、广告或云端付费能力；
- 无限层级文件夹、嵌套构思集或复杂标签系统。
- 热敏机、蓝牙打印、ESC/POS 或厂商打印 SDK；
- 模板市场、字体上传、贴纸、素材包或深度 DIY；
- Web、PWA、Android、macOS 或其他平台版本。
- 锁屏常显、锁屏小组件、Live Activity 或其他持续占用锁屏的展示能力；如未来需要，单独立项评估隐私、耗电与系统约束。

## 5. 信息架构

四个一级页面固定为：

`灵感｜卡片预览｜构思集｜小票册`

- 四个入口地位平等，底部点击始终可达；
- 支持固定顺序的一级页面横滑，首尾不循环；
- 页面内对象手势优先，具体冲突规则由设计规格定义；
- 右下浮动“+”显示在灵感、卡片预览和构思集，小票册不显示；
- 三页复用同一浮动组件，但分别执行“记录灵感”“新增卡片”“新建构思集”；
- 搜索、选择、录入、附件选择、详情和键盘编辑等覆盖状态下隐藏浮动“+”。
- 四个一级页面的左上角统一为全局菜单，且只包含“回收站”和“设置”；
- 四个一级页面的搜索入口固定在右上角最右侧，历史入口始终排在搜索左侧；
- 四页的历史按钮均进入同一个“全局历史中心”，不再根据来源页面打开不同历史页。

## 6. 功能需求

### 6.1 灵感

- 默认首页按时间显示全部独立灵感，默认从新到旧；
- 支持新到旧、旧到新排序、全局搜索和批量管理；
- 灵感可包含文字、照片、普通文件、语音灵感或音频附件；
- 语音灵感在权限与系统能力可用时使用本机简体中文转写，并始终保留原录音；转写不可用或中断不能导致录音丢失；
- 音频附件通过现有文件入口选择，可播放但不自动转写；不额外增设与文件入口并列的音频按钮；
- 麦克风录制和文件导入是两种明确的声音来源，不互相覆盖；
- 文字或附件至少存在一项，空内容不得保存；
- 点按灵感进入完整编辑页；
- 编辑页支持自动保存、离开前保存、附件新增、预览、播放和单独移除；
- 新建灵感由用户明确点按“保存”后落盘；编辑已有灵感时自动保存，点按“完成”退出编辑；
- 默认字号进入编辑页后自动聚焦；最大辅助字号不自动拉起键盘，避免内容空间被过度压缩；
- 删除进入回收站，不直接永久删除。

### 6.2 卡片预览

- 只显示未归入构思集且仍在卡片流中的独立灵感；
- 卡片不再平铺占满整个页面；当前卡与背后卡保留可见边界、留白和层次，让用户理解这是可翻阅的卡片堆；
- 上下滑切换前后卡片，首尾不循环；
- 左滑越过阈值后收起当前灵感，未过阈值回弹；
- 收起后短时提供“撤回”，且不阻断继续翻卡；
- 点按当前卡片进入完整编辑页；
- 编辑返回、切换一级页或重启 App 后，优先恢复到仍存在的同一对象，而不是数组下标；
- 卡片表达文字及照片、文件、PDF、音频等附件状态。

### 6.3 快速归入构思集

- 卡片底部保留一个“归入构思集”圆形按钮；
- 按钮的纸张/玻璃材质、颜色、阴影和光学尺寸必须与卡片预览一致，不得像后加的系统默认按钮；
- 点按提供等价操作入口；长按并上拖时，固定同时展开“新建构思集”和“归入现有构思集”两个目标；
- 点按必须有明确按压/释放反馈；长按达到阈值后，两个目标从中心按钮连续展开，高亮、取消和回收均不得瞬间跳变；
- 两个目标不随当前构思集数量变化；
- 已有 5 个构思集时仍显示“新建构思集”，容量限制在后续新建确认阶段提示；
- 没有构思集时仍显示“归入现有构思集”，进入空列表提示且不写入数据；
- 用户只拖拽一次，松手选择操作类型，之后通过面板或列表点按完成；
- 目标外松手取消，不改变数据；
- 已满 10 条的构思集保持可见但不可接收，选择后说明容量原因。

### 6.4 构思集与构思轮次

- 同时最多 5 个构思中的构思集；
- 每个构思集最多 10 条灵感；
- 一条灵感同一时间最多属于 1 个构思集；
- 归入后不再出现在卡片预览中；
- 自动名称依次为“构思集（1）”“构思集（2）”……，删除后编号不复用；
- 构思集可改名，不允许嵌套；
- 构思集总页始终显示右下浮动“+”，达到 5 个时按钮仍可见，点按后提示容量限制；
- 从总页新建进入临时工作台，产生正文、附件或有效名称后才落盘；
- 工作台支持组内灵感切换、原位编辑、附件访问、调整顺序、移出和新增；
- 空轮次不能结束，也不能生成空小票；
- 结束本轮前必须确认，取消不改变数据；
- 同一时间每个构思集只有一个构思中的轮次。

### 6.5 构思小票与小票册

- 一轮构思严格对应一张构思小票；
- 小票冻结结束时的构思集名称、时间、成员顺序、正文、附件元数据和过程事件；
- 每张小票至少包含 NOTE1 标识、唯一编号、构思集名称、开始/结束/持续时间、灵感数量、有效编辑次数、附件数量、最终文字数量、克制时间线、成员正文与附件摘要；
- 小票使用真实轮次数据展示“第 N 轮构思”，不得用有效编辑次数推导轮次；
- 票面紧凑展示灵感数量、附件数量、最终文字数量和有效编辑次数，详情提供完整统计说明；
- 一次进入编辑且内容实际变化并结束编辑计为一次有效编辑，不按按键、自动保存或光标变化累计；
- 原灵感后续编辑、移动或删除不改写旧小票；
- 小票册以单张长票为主对象，支持左右切换，首尾不循环；
- 小票需要呈现可识别的真实票据质感，包括纸张比例、纸色、边缘、排版密度、编号与时间等票据信息层级；不能只是一张白色长卡片；
- 左右换票时，当前票、前后票和票据夹必须连续跟手并有深度关系，不使用突然切换或单纯淡入淡出代替空间过渡；
- 从票据夹或顶部把手下拉抽取进入详情，点按小票也可进入；
- 提供经典票和胶卷票。照片少于 3 张且大部分成员以文字为主时推荐经典票；照片达到 3 张或超过一半成员含照片时推荐胶卷票；推荐只决定默认模板，用户可切换；
- 支持 PDF、Markdown、纯文本导出，以及系统分享、复制、查找和删除；PDF 默认 A4 纵向、窄幅内容列居中，图片保持比例并使用可用高分辨率资源；
- 小票册不显示右下新增按钮；
- “继续构思”在原构思集下开启新一轮，默认带回上一轮成员和顺序，不复制同名构思集；
- 已有 5 个活动构思集时阻止继续构思，不替换现有内容。

### 6.6 搜索、选择与删除

- 全局搜索覆盖灵感正文、构思集名称、小票快照内容和附件名；
- 搜索结果进入真实对象，不进入静态副本；
- 搜索范围顺序为全部、灵感、构思集、小票；
- 四个一级页面均常驻页面级搜索入口；单个构思集工作台和灵感编辑页不常驻搜索，小票详情只在“更多”中提供当前小票查找；
- 灵感页左上全局菜单不再提供“选择”；长按任一灵感进入批量选择状态，并默认选中被长按的灵感；
- 批量归入、删除、恢复和永久删除必须原子化，失败时不得部分写入；
- 灵感、构思集和小票按各自最小对象删除；
- 回收站支持恢复、永久删除、清空和 30 天过期规则；
- 永久删除前二次确认；仍被灵感、小票或回收站引用的附件文件不能清理。

### 6.7 全局历史中心

- 四个一级页面都显示历史按钮，点按后进入同一个全局历史中心；
- 中心默认显示“全部”，页面内通过分类按钮切换要查看的历史类型，交互层级参照全局搜索的范围切换；
- 分类文案确认为“全部、已收起、构思历程、小票”；
- 顶部参照全局搜索的“当前范围”结构，清楚显示并支持切换当前分类；
- “全部”将三类历史按时间倒序混合排列，每项明确标识对象类型；
- “已收起灵感”只显示退出卡片流但未删除的独立灵感；“构思历程”显示已结束的构思集与轮次；“构思小票”显示已生成的不可变快照；
- 全局历史中心内不再放置搜索按钮或搜索框；需要按关键字查找时，用户返回一级页面使用全局搜索；
- 回收站不属于历史分类，仍由左上全局菜单独立进入；活动构思集和仍在卡片流中的灵感不冒充历史内容。
- 历史列表不常驻恢复或继续构思按钮；点按条目进入对应详情后，再提供“放回卡片流”或“继续构思”等对象动作。

批量能力固定为：

| 页面 | 批量操作 |
| --- | --- |
| 灵感 | 删除、放回卡片流、归入构思集 |
| 构思集总页 | 不支持 |
| 构思历程 | 不支持 |
| 小票册 | 导出 PDF、系统分享、删除 |
| 全局搜索结果 | 只有筛选为单一对象类型后才提供对应操作 |
| 卡片预览、工作台、编辑页、小票详情 | 不支持 |

删除和恢复关系：

- 回收站只保存可独立恢复的灵感和构思小票，不保存构思集或构思轮次；
- 删除构思集时，成员分别作为独立灵感进入回收站，已生成小票不变；
- 删除属于构思集的单条灵感时，构思集移除该成员；若因此变为空组，只移除该关联空组；
- 恢复灵感后成为独立灵感并放回卡片流，不自动重建原构思关系；
- 删除小票不影响来源构思集、轮次和灵感。

### 6.8 本机备份、恢复与设置

- 备份覆盖全部 V0.3 领域对象、回收站和仍被引用的附件；
- 恢复前说明会影响当前本机数据并二次确认；
- 恢复失败不得破坏当前有效数据；
- 损坏数据库进入保护状态，不用空数据覆盖原文件；
- 设置包含本机备份与恢复、本机隐私说明、联系邮箱和真实版本号；
- 不显示账号、云同步、AI、会员或其他占位项。

## 7. 核心业务规则

| 规则 | 要求 |
| --- | --- |
| 活动构思集上限 | 5 个 |
| 单个构思集成员上限 | 10 条 |
| 灵感归属 | 同一时间最多属于 1 个构思集 |
| 卡片流 | 已归入构思集或已收起的灵感不参与 |
| 小票 | 结束一轮生成一张不可变快照 |
| 撤回结束 | 只允许撤回最新且仍在时间窗口内的结束结果，不留下孤立轮次或重复结束事件 |
| 附件生命周期 | 任一有效对象仍引用时不得删除底层文件 |
| 批量操作 | 全部成功或全部失败 |

## 8. V0.3 当前增量范围

V0.3 在不改变产品核心结构的前提下，基于当前已开发完成的 V0.2 单一路径继续产品化：

- 统一四个一级页面的视觉层级和组件语言；
- 优化布局、手势反馈、键盘、长内容、窄屏和辅助字号表现；
- 补齐错误、容量、空态、编辑态和无障碍状态；
- 补齐真机 VoiceOver、真实附件、分享、系统版本与材质降级证据；
- 保持当前领域规则、数据、附件、搜索、回收站、备份和小票快照能力不回归。

已确认的 V0.3 决策：

## 9. 验收条件

### 9.1 用户闭环

- 用户可离线完成记录 → 预览 → 收起或归入 → 构思 → 结束 → 小票 → 分享或继续构思；
- 用户能理解“收起”不是删除，“结束本轮构思”不是删除构思集；
- 四个页面之间转换自然，返回后对象身份和编辑内容不丢失。

### 9.2 数据与边界

- 5 个构思集、每组 10 条和单卡单组规则在 UI 与领域层一致；
- 结束、撤回、继续构思和批量操作不产生重复、孤立或部分写入；
- 小票快照不被后续编辑改写；
- 备份、恢复、回收站和附件清理保持引用完整性。

### 9.3 运行质量

- 覆盖默认、空、长内容、编辑、错误、键盘、默认字号、最大辅助字号和窄屏；
- VoiceOver、减少动态效果和减少透明度下仍可理解并完成核心操作；
- iOS 17–当前支持版本的材质降级不影响可读性和命中；
- 构建、测试或单张截图不能代替真机手势、附件、分享和 VoiceOver 验收。
