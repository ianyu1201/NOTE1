## 0. 文档定位

本文件是 NOTE1 V0.2 的**增量 PRD**，只记录相对于冻结 V0.1 基线新增、改变或取消的产品要求，以及这些变化形成的 V0.2 完整业务闭环。

V0.1 已经具备且 V0.2 继续沿用的基础能力，不在这里重复展开；开发与验收通过非回归矩阵确认。页面长相、组件状态、动效、手势细节、确认图和反例不堆入本文件，统一由产品设计与交互规格承接。

### 0.2 产品定位

NOTE1 是一个低压力、完全在本机运行的原生 iPhone 灵感记录 App，继续坚持：

> 简单记，快速看。

V0.2 不复制 flomo 的标签、长期知识管理、跨端积累、日历统计或 AI 关联检索。产品资源集中在短周期闭环：

```text
记录灵感 → 卡片预览 → 收起或归入构思集
→ 在构思集内反复推演 → 结束本轮构思
→ 生成构思小票 → 阅读、保存、分享或带到其他工具
```

V0.2 两项核心亮点：

1. **卡片流**：通过上下滑动重新进入灵感；
2. **构思小票与小票册**：把一轮构思保存为可见、可收藏、可带走的成果。

### 0.3 体验目标

- 记录时轻量：不要求先分类、选项目或整理结构；
- 预览时低压力：一张一张看，不引入任务催促；
- 构思时重新激发：在有限卡片之间反复切换、补充和排序；
- 结束时有成果：一轮构思形成一张固定小票，而不是积分、排名或效率评分。

### 0.4 标准名词

| 标准名称 | 定义 | 旧称或易混名称 |
| --- | --- | --- |
| 灵感 | 用户保存的一条独立内容，可含文字和附件 | 想法、记录、笔记 |
| 卡片预览 | 用户上下翻阅灵感的功能 | 回看、卡片回看 |
| 卡片流 | 当前可以上下切换的卡片集合 | 回看流 |
| 收起 / 已收起 | 独立灵感退出卡片流但不删除 | 完成 / 已完成 |
| 放回卡片流 | 把已收起灵感重新加入卡片流 | 恢复、放回预览 |
| 构思集 | 用户正在集中构思的一组灵感 | 灵感组、想法组、推进组 |
| 归入构思集 | 将灵感加入一个构思集 | 归组、加入灵感组 |
| 构思中 / 已结束 | 构思轮次状态 | 未完成 / 已完成 |
| 结束本轮构思 | 结束当前轮次并生成小票 | 完成组、结束本轮 |
| 继续构思 | 从已结束构思集或旧小票开启新一轮 | 恢复组、继续推进 |
| 构思轮次 | 从开始构思到结束本轮的一段过程 | 推进轮次 |
| 构思历程 | 查看已结束构思集和历次轮次的空间 | 过往、历史构思 |
| 构思小票 | 一轮构思结束后的固定成果 | 推进小票、整理稿 |
| 小票册 | 保存全部构思小票的一级页面 | 小票夹、小票仓库 |
| 经典票 / 胶卷票 | 文字信息型 / 多照片型小票模板 | 文字票 / 胶片票 |
| 语音灵感 | 用户现场录制、可播放并可保留转写文字的灵感 | 语音录入 |
| 音频附件 | 用户导入的会议录音、音乐等可播放文件 | 语音附件 |

独立灵感使用“收起 / 放回卡片流”；构思集使用“结束本轮构思 / 继续构思”。“完成 / 恢复”不再作为跨对象通用词。

## 1. V0.1 → V0.2 版本差异

### 1.1 继续沿用，不在本 PRD 重复定义

- 原生 SwiftUI iPhone App、最低 iOS 17、竖屏优先；
- 完全本机保存、离线可用、无账号、无后端、无云同步；
- 灵感文字与附件独立保存；
- 完整灵感编辑、自动保存、照片与文件附件、Quick Look；
- 卡片上下翻阅、左滑状态反馈、短时撤回和位置恢复；
- 本机备份与恢复、中文环境和辅助功能基础。

以上能力以 V0.1 冻结 PRD和非回归矩阵为准。V0.2 新结构不得把它们简化为功能缩水的弹窗或静态骨架。

### 1.2 明确改变

| V0.1 | V0.2 |
| --- | --- |
| 记录首页、卡片回看、灵感组、历史等分散入口 | 四个稳定一级入口：灵感、卡片预览、构思集、小票册 |
| 首页只显示最近灵感，历史管理全部记录 | “灵感”首页直接显示全部独立灵感 |
| 普通灵感“完成 / 已完成” | “收起 / 已收起”，只表示退出卡片流 |
| 灵感组是近似分类目录 | 构思集是有限、正在推进的一组思考 |
| 组内纵向时间线 | 纵向叠卡工作台，可反复切换、原位编辑和排序 |
| 完成构思组后只改变状态 | 结束当前构思轮次并生成一张构思小票 |
| 历史混合管理灵感和组 | 灵感、构思历程和小票册各自承担单一职责 |
| 所有删除直接走永久确认 | 删除先进入 30 天回收站，旧小票快照保持固定 |

### 1.3 明确取消

- 独立安静首页与“最近 5 条”限制；
- 左上角“全部灵感”抽屉；
- “当前 / 已完成 / 未完成”的通用状态筛选；
- 把构思集当成无限分类目录；
- 构思集与成员卡片在卡片流重复出现；
- 以普通列表或时间线作为构思集的主要工作方式；
- 在“构思集”和“小票册”一级页面显示全局新增灵感按钮；
- 把全部灵感、构思集和小票混在一个历史列表中。

### 1.4 V0.2 新增

- 构思集容量、轮次和继续构思；
- 构思小票、经典票、胶卷票、小票册、PDF 与分享；
- 语音灵感与音频附件双模式；
- 全局对象搜索、页面范围搜索和按对象批量处理；
- 回收站、30 天自动清理和附件引用生命周期；
- 四个一级页面横滑切换和完整手势冲突规则。

## 2. 信息架构与一级页面

底部一级入口固定为：

```text
灵感｜卡片预览｜构思集｜小票册
```

- **灵感**：默认首页，显示全部独立灵感，负责快速录入、排序、搜索和管理；
- **卡片预览**：纵向卡片流，负责快速翻阅、收起和归入构思集；
- **构思集**：显示构思中的构思集，负责继续、新建和进入构思历程；
- **小票册**：显示全部构思小票，负责浏览、搜索、选择、导出和分享。

四个入口层级平等，底部点击始终可达；同时支持按固定顺序横滑切换，首尾不循环。对象手势优先级见产品设计与交互规格。

### 2.1 浮动新增入口

- 统一的右下角浮动“+”出现在“灵感”“卡片预览”和“构思集”三个一级页面；“小票册”不显示新增按钮；
- 三页使用同一组件与悬浮位置，但分别执行“新增灵感”“新增卡片”“新建构思集”；
- 按钮覆盖在当前内容层之上，只避开底部一级导航、键盘与安全区，不得为按钮预留独立模块、固定空白行或大面积空白；
- 搜索、选择、录入、附件选择、详情和键盘编辑状态下隐藏。

### 2.2 灵感首页

- 直接按时间显示全部独立灵感，默认从新到旧；
- 构思中、已结束构思集内、已收起或仍在卡片流中的灵感都保留为独立记录；属于构思集时显示“构思集 · 名称”；
- 顶部左侧统一功能入口包含“选择灵感、回收站、设置”；中间 `NOTE1⌄` 提供新到旧/旧到新排序；右侧进入全局搜索；
- 最近 7 个自然日可显示一行克制摘要：“本周新增 N 条灵感 · 结束 M 轮构思 · 留下 K 张小票”；全为 0 时隐藏；
- 不显示使用时长、连续天数、排名、完成率或压力指标；
- 卡片主体点按进入完整灵感编辑。

首页视觉以产品设计与交互规格中的“首页融合确认稿”为 A 级目标。

### 2.3 构思集与构思历程层级

```text
构思集
 ├─ 构思中的构思集
 └─ 构思历程
     └─ 已结束构思集与历次构思轮次

小票册
 └─ 全部构思小票
```

构思集总页只显示构思中内容；构思历程管理已经结束的思考线及其轮次；小票册独立管理构思成果。轮次与小票互相保留来源入口，但不复制数据或混合列表职责。

## 3. 核心对象与业务规则

### 3.1 灵感

- 灵感是最小内容对象，可包含文字、照片、文件、语音灵感或音频附件；
- 纯空白且无附件时不能保存；
- 归入构思集后仍可在灵感首页单独找到；
- “收起”只改变是否参与卡片流，不删除、不生成小票；
- 已收起灵感可放回卡片流或直接归入构思集。

### 3.2 构思集

- 同时最多 5 个构思中的构思集；
- 每个构思集最多 10 条灵感；
- 一条灵感同一时间最多属于 1 个构思集；
- 归入后，成员不再出现在卡片预览中；卡片预览只负责重新遇见未归入构思集的独立灵感，已归入内容统一从“构思集”一级入口进入工作台；
- 第 6 个构思集或第 11 条成员不得部分写入，显示容量原因；
- 自动名称依次为“构思集（1）”“构思集（2）”……；编号单调递增，删除后不复用；
- 构思集可以改名，不允许嵌套、标签化或无限扩容。

### 3.3 新建与临时构思集

- 构思集总页始终保留右下角悬浮“+”；空态同样显示。达到 5 个时按钮仍可见，点按后从页面下方短暂提示“当前版本只支持 5 个构思集”；
- 从总页新建时进入带第一张空白灵感的临时工作台；产生正文、附件或有效名称后才落盘；
- 无内容、无附件且未改名便退出时自动丢弃，不占容量；
- 卡片预览中选择“新建构思集”后进入点击式新建面板；确认新建后使用默认名称创建构思集并归入当前灵感，之后允许改名。

### 3.4 快速归入构思集

- 卡片预览底部构思集按钮支持长按后拖拽；拖拽只发生一次，用于选择“新建构思集”或“归入现有构思集”这一操作类型；
- 无论当前已有多少个构思集，长按后始终同时显示“新建构思集”和“归入现有构思集”两个拓展目标；构思集数量上限在后续新建确认时提示，不能提前隐藏操作类型；没有任何构思集时，点击“归入现有构思集”进入空列表提示，不写入数据；
- 手指移动到有效拓展目标后即可松手。松手结束拖拽并打开对应的点击式面板，不要求继续拖到具体构思集；
- “新建构思集”打开新建面板；“归入现有构思集”打开现有构思集列表，用户通过点按具体名称完成归入；
- 现有构思集列表显示名称和 `当前数量/10`。达到 10 条的构思集保持可见但不可接收；用户尝试选择时提示“当前版本每个构思集只支持 10 条灵感”，本次归入失败且不产生部分写入；
- 拖拽过程中构思集按钮本体不跟手；手指离开全部拓展目标后取消高亮，面板外松手不打开后续面板、不改变数据；
- 点按和无障碍操作必须提供与上述两类操作等价的非拖拽入口，但不得改变容量规则。

### 3.5 构思轮次

- 一个构思集可以先后产生多轮构思；同一时间只有当前轮处于“构思中”；
- 结束本轮时，当前全部成员、顺序、正文、附件和过程事件形成固定快照；
- 一轮严格对应一张构思小票；取消确认不改变任何数据；
- 结束后构思集及成员退出当前卡片流，但思考线仍可在构思历程找到；
- “继续构思”在原构思集下开启新一轮，默认带回上一轮成员和顺序，不复制同名构思集；
- 已有 5 个构思中构思集时阻止继续构思，不替换现有内容；
- 新轮次可以增删成员、编辑和排序；旧小票不被覆盖。

### 3.6 构思小票

- 构思小票是构思轮次结束时生成的不可变成果快照；
- 原灵感之后编辑、删除、移除附件或再次构思，不改变旧小票；
- 模板可以在经典票和胶卷票之间切换，但只改变表现，不改写快照；
- 删除小票不影响来源构思集、轮次或灵感。

## 4. 核心用户流程

### 4.1 快速记录

1. 用户在灵感或卡片预览页点按浮动“+”；
2. 底部聊天式录入面板出现；
3. 用户输入多行文字，或添加照片、文件、语音灵感和音频附件；
4. 保存后生成一条独立灵感，清空本次待提交内容并返回来源页。

长文字光标、附件选择、键盘收起、保存可达性和本机播放必须符合设计规格与非回归矩阵。

### 4.2 卡片预览与收起

1. 用户上下滑动切换卡片；
2. 点按独立灵感进入完整编辑；
3. 向左滑动独立灵感，越阈值后执行“收起”；
4. 底部显示约 2 秒“已收起 / 撤回”，且不阻断继续翻卡；
5. 用户可在灵感页将其放回卡片流。

卡片预览只展示未归入构思集的独立灵感。构思集及其成员不在卡片预览重复占位，统一从“构思集”一级入口进入；卡片预览的主卡片从标题下方铺满到下方一级入口的上沿，“归入构思集”按钮悬浮在当前卡片底部，不再占用独立的底部操作槽。

卡片左滑状态背景、完整编辑、附件、自动保存和位置恢复不得因 V0.2 重构而丢失。

### 4.3 构思集工作台

- 进入构思集即进入纵向叠卡工作台，不增加第二次“专注编辑”；
- 支持最多 10 张成员卡片快速切换、原位编辑、附件访问、排序、移出和新增组内灵感；
- 键盘显示时正文滚动优先，暂停纵向切卡；
- 工作台中的单张成员左滑不执行“收起”，也不结束整轮；
- 结束本轮是构思集级操作。

### 4.4 结束本轮与小票生成

1. 用户在构思集工作台内点按等价结束入口；
2. 系统显示“结束本轮构思？”确认；
3. 取消后恢复原位；
4. 确认后原子结束轮次并保存一张小票；
5. 数据保存成功后播放“出纸—内容显现—停止收束”动效；
6. 用户可以进入新小票、返回或在约 2 秒内撤回本次结束；
7. 撤回同时恢复轮次、成员和卡片流，并删除本次刚生成的小票，不留下孤立数据。

### 4.5 小票册浏览

- 根页一次聚焦一张长条小票，页面可纵向阅读完整内容；
- 根页标题居中，右上固定为“搜索”和三点“更多”；“选择”从“更多”菜单进入，不作为独立常驻按钮；
- 左右滑动切换前后小票，首尾不循环；
- 从票据夹/顶部把手下拉抽取进入详情；当前票已滚动到顶部时也可在方向明确后触发；
- 点按小票提供等价详情入口；
- “更多”菜单统一承接选择、切换模板、导出 PDF、分享、复制、在小票中查找和删除；根页及详情均不常驻底部操作栏；
- 详情承接附件预览、模板切换、导出、分享、查找和来源轮次，顶部仍使用返回、居中标题和三点“更多”；
- 根页不使用普通列表、文件网格、瀑布流、固定高度短白卡或不可读长图缩略图。

## 5. 构思小票内容与导出

### 5.1 小票内容

每张小票至少包含：

- NOTE1 标识和小票唯一编号；
- 构思集名称；
- 本轮开始、结束和持续时间；
- 灵感数量、有效编辑次数、附件数量和最终文字数量；
- 克制的时间路线；
- 按工作台顺序排列的卡片正文；
- 照片、音频、PDF 和其他附件摘要及归属；
- “本轮构思已结束，N 条灵感已收录”。

一次进入编辑且内容实际变化并结束编辑，计为一次有效编辑；不得按每个按键、自动保存或光标变化累计。

### 5.2 模板

- **经典票**：文字、数字和少量图片为主；
- **胶卷票**：照片、绘画、扫描件和视觉参考为主，尽量保留原始比例；
- 照片少于 3 张且大部分卡片以文字为主时默认经典票；照片达到 3 张或超过一半卡片含照片时默认胶卷票；
- 推荐只决定默认模板，用户可一键切换；
- V0.2 不提供自由拖拽、字体上传、贴纸、模板市场或深度 DIY。

### 5.3 PDF、分享与复制

- App 小票和 PDF 使用同一份内容数据和排版顺序；
- 首版 PDF 默认 A4 纵向，窄幅内容列居中，按卡片、时间线和附件块分页；
- 图片保持比例和可辨识质量；PDF 使用高分辨率资源，不放大屏幕缩略图；
- PDF 可通过系统分享保存或普通打印；V0.2 不连接热敏机或厂商 SDK；
- 用户可以复制干净纯文本或 Markdown，便于交给备忘录、Obsidian、Codex 等工具。

## 6. 搜索、选择、删除与设置

### 6.1 搜索

- 灵感页右上进入全局搜索，支持 `全部 / 灵感 / 构思集 / 小票` 单选范围；
- 构思集、构思历程和小票册内进入搜索时自动限定并显示当前对象范围；
- 搜索框位于页面上方，范围筛选紧邻其下；
- 结果必须标明对象类型并进入真实对象；
- 卡片预览、单个构思集工作台、灵感编辑页不常驻搜索；
- 小票详情只在“更多”中提供“在小票中查找”；
- V0.2 只做本机关键词搜索，不做 OCR、标签、语义检索、AI 或 RAG。

### 6.2 批量选择矩阵

| 页面 | 搜索 | 批量选择 |
| --- | --- | --- |
| 灵感 | 全局搜索 | 删除、放回卡片流、归入构思集 |
| 构思集总页 | 当前范围 | 不支持 |
| 构思历程·已结束构思集 | 当前范围 | V0.2 不支持 |

| 卡片预览 | 不常驻 | 不支持 |
| 单个构思集工作台 | 不常驻 | 主工作台不支持 |
| 灵感编辑页 | 不支持 | 不支持 |
| 小票详情 | 小票内查找 | 不支持 |

批量归入必须检查目标剩余容量和单卡单组规则；批量操作全成或全不成，不允许部分写入。

### 6.3 回收站与级联

- 回收站只保存可独立恢复的灵感和构思小票，不保存构思集或构思轮次；
- 删除构思集时，成员分别作为独立灵感进入回收站；已经生成的小票保持不变；
- 删除属于构思集的单条灵感时，构思集减少该成员；变为空组时自动移除空组，不生成小票；
- 恢复灵感后成为独立灵感并放回卡片流，不自动重建原构思关系；
- 删除小票不影响来源构思集、轮次和灵感；
- 回收站对象保留 30 天，页面显示“在回收站中超过 30 天的灵感将会自动删除”；
- 恢复、永久删除、清空和自动过期必须保持附件引用安全。

不显示账号、云同步、AI、会员或其他占位项。

## 7. 附件、声音与本机数据

### 7.1 声音双模式

- 语音灵感：用户现场录制，原始声音本机保存、可播放，可同时保存本机转写文字；
- 音频附件：用户导入会议录音、音乐等已有音频，可播放，不自动转写；
- 两者记录来源类型但共用不可变声音资源和播放器；
- 转写失败不删除录音，播放失败不删除文字；
- V0.2 不做云端转写、自动会议纪要、说话人识别、音频剪辑或后台播放。

### 7.2 附件与小票快照

- 照片在小票中直接显示；音频显示可播放条；PDF 和其他文件显示名称、类型、大小和可用首页预览；
- 点按 PDF 和文件使用系统预览，不把整份文件强行展开在窄票中；
- 灵感、小票和回收站对象分别持有不可变资源引用；
- 只要任一对象仍引用附件，底层文件不得删除；
- 小票永久删除后只移除该小票引用，没有任何引用时才清理资源。

### 7.3 本机备份与数据版本

- 备份覆盖灵感、构思集、构思轮次、小票、回收站对象和仍被引用的附件；
- 恢复前说明会影响当前本机数据并二次确认；
- V0.1 测试数据不迁移，V0.2 使用新的本机数据版本；
- V0.2 仍无账号、后端、自动云备份或云同步。

## 9. 完整验收闭环

### 9.1 功能验收

1. 用户可离线完成：记录 → 预览 → 收起/归入 → 构思 → 结束 → 小票 → 分享/继续构思；
2. 5 个构思集、每组 10 条和单卡单组规则在 UI 与数据层一致；
3. 结束一轮只生成一票，取消不生成，撤回不留下孤立轮次或小票；
4. 旧小票不随原灵感、附件或后续轮次变化；
5. 搜索结果进入真实对象，批量操作不部分写入；
6. 回收站、30 天过期、恢复、永久删除和附件清理闭环可验证；
7. 语音灵感和音频附件均可播放，转写与原录音互不覆盖；
8. 本机备份与恢复覆盖 V0.2 全部对象。

### 9.2 UI/UX 验收

所有页面按 `NOTE1_V0.2_产品设计与交互规格.md` 提交同尺寸目标图与实现图；所有核心手势提交完成与取消录屏。缺 A 级页面确认稿的页面，先完成视觉检查点，不允许开发人员自由补齐最终样式。

### 9.3 非回归验收

按照非回归矩阵逐项证明：全屏与安全区、主题、启动、中文环境、长文字录入、照片/文件附件、Quick Look、卡片左滑反馈、撤回、完整编辑、自动保存、位置恢复和辅助功能没有丢失。

### 9.4 工程验收

- 相关 XCTest 和完整测试通过；
- iPhone 模拟器构建通过；
- 至少一台小屏模拟器、主模拟器和实体 iPhone；
- iOS 26 Liquid Glass 与至少一个 iOS 17–25 降级环境；

- 文字、照片、语音、PDF 和多附件真实样本；
- 当前实现问题按独立 ISSUE 文档逐项关闭。
