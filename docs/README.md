## 目录职责

| 目录 | 职责 | 是否参与当前裁决 |
| --- | --- | --- |
| `00_项目治理/` | 会话交接、协作流程、方案索引和目录规则 | 是，负责入口与流程，不定义产品需求 |
| `01_产品/` | 分版本 PRD、范围、产品方向和待讨论项 | 是 |
| `02_设计/` | 产品设计规格、确认视觉、候选视觉和 V0.3 设计探索 | 是；候选图除外 |
| `03_工程/` | 现役开发规范、非回归矩阵、ISSUE 和工程风险 | 是 |
| `04_技术决策/` | 已接受 ADR | 是 |
| `90_历史归档/` | 已完成任务单、过程计划和历史审计 | 否，只提供历史证据 |

## 信息源优先级

1. 用户在当前产品会话中的最新明确确认；
2. V0.2 增量 PRD；
3. V0.2 产品设计与交互规格；
4. V0.1 → V0.2 非回归矩阵；
5. V0.1 冻结 PRD；
6. 当前 ISSUE；
7. V0.3 复盘与候选建议；
8. 代码和测试只说明当前实现；
9. 历史归档和外部参考不参与产品裁决。
