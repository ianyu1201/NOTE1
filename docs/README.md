## 裁决顺序

1. 用户在当前正式产品任务中的最新明确确认；
2. V0.3 PRD；
3. V0.3 产品设计与交互规格；
4. V0.3 开发与运行验收基线；
5. 已接受 ADR；
6. 当前代码、测试和证据只说明现状，不自动覆盖产品目标。
