## 2. 视觉判断

- 与唯一现役参考 `90_历史归档/V0.3/运行证据/确认视觉/NOTE1_V0.3_小票黑白热敏票据参考.png` 同批对照：当前票面继续使用中性近白纸、黑色等宽打印、居中票头、有限粗体、双线/虚线和标签—数值对齐；未回退到黄色或牛皮纸。
- 当前实现保留照片条、票据夹和移动端动态字体，这是 NOTE1 内容与手机阅读约束，不照搬外部参考的 Claude 字段、金额、二维码或打印机能力。
- 四页共享的是 NOTE1 顶部、8pt 起始线、22pt 外沿、字号层级和克制阴影节奏；不同纸张对象不强行共用同一圆角。
