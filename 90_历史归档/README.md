## 归档规则

- `03_工程/` 只保存现役工程、测试和运行验收合同，不再保存已关闭版本的证据树。
- 活动版本的设计候选放在 `02_设计/视觉素材/`；运行取证路径由该版本 S3 合同明确。
- 版本关闭后，需保留的运行材料迁入 `90_历史归档/<版本>/运行证据/`，并同步修复索引与引用。
- 截图、录屏、日志和语义快照只证明对应提交、设备、系统和操作范围内发生过什么，不自动定义需求、批准视觉或关闭风险。
- 模拟器结果不能替代真机、触觉、真实权限、VoiceOver、系统分享目的地或跨系统版本验收。
- 历史失败、否决或未完成验收的材料必须保留原身份，不得改写成通过结论。

本次治理只移动路径并修复引用，没有删除 V0.1–V0.3 的任何运行材料。
