## 2. 问题与修正

原实现同时使用原生 `toolbar` 和自定义 `notePrimaryHeader`，导致四页的垂直位置、标题字重、按钮尺寸、材质和阴影不一致。本批统一为共享 `V02PrimaryPageHeader`：

- 四页中间均显示 `NOTE1`；
- 左侧均为同一全局菜单，右侧均为历史、搜索；
- 顶部高度 56pt，水平安全边距 22pt；
- 圆形按钮实际命中区 48pt、可见材质 46pt，按钮间距 4pt；
- 标题菜单的指示符独立布局，不再推移 `NOTE1` 的光学中心。
