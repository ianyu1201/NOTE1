# NOTE1 V0.3 卡片与归入边界证据索引

> 日期：2026-08-09
> 性质：细节优化第五批运行抽样，不是用户确认的最终视觉稿

## 1. 本批范围

- 卡片预览第一张向前、最后一张向后拖拽时只显示 24% 阻尼，不再整张跟手离开后突然弹回；
- 64pt 实际位移 / 96pt 预测位移以下保持当前卡，过阈值才切换相邻卡，首尾不循环；
- “归入构思集”仍固定为“新建构思集 / 归入现有构思集”两个目标；上拖超过 18pt 揭示托盘，超过 50pt 且最终命中目标才提交，目标外或距离不足均取消；
- 减少动态效果下缩短切卡位移与时长，并保留按钮按压、托盘展开和取消结果。

## 2. 证据清单

- `01_卡片首尾阻尼与未过阈值回弹.mp4`：最后一张向后阻尼、有效方向未过阈值回弹、切到第一张、第一张向前阻尼及切回；
- `02_归入按钮长按展开_目标外取消_目标提交.mp4`：长按按压与托盘显现、目标外下拖取消、再次展开后命中“归入现有构思集”、二级列表出现并取消；未写入业务数据；
- `03_减少动态效果_切卡与归入取消.mp4`：系统 Reduce Motion 为开启状态时，卡片首尾/切换与归入托盘取消的结果关系保持。

## 3. 运行环境与结果

| 场景 | 环境 | 结果 |
| --- | --- | --- |
| 卡片首尾与阈值 | NOTE1 Evidence iPhone 15 Pro，iOS 26.5 模拟器，浅色、默认字号 | 2 张卡片均可到达；第一张/最后一张越界拖拽呈阻尼并回原位；未过阈值不换卡，有效方向过阈值切相邻卡 |
| 归入按钮 | 同上 | 长按保留按压反馈并展开固定双目标；目标外拖拽取消；命中“归入现有构思集”进入真实二级列表，取消后原卡不变 |
| 减少动态效果 | 同上；录制前系统 `ReduceMotionEnabled` 查询为 `1` | 切卡位移与收束缩短，长按、托盘展开和取消仍可理解 |
| 自动化 | iOS 26.5 模拟器 | 80 项 XCTest 全部通过；新增卡片首尾 24% 阻尼、归入托盘 -18pt/-50pt 阈值及目标外取消断言；模拟器构建通过 |

取证完成后，主模拟器已恢复默认字号和关闭 Reduce Motion。

## 4. 证据边界

- 自动化工具将“长按展开”和“从按钮拖向目标”分成两个连续动作；真实手指一次长按上拖、拖动途中目标高亮与触感仍需真机原生录屏；
- 本批运行数据为 2 张卡片、4 个构思中的构思集；0/5 个构思集、10 条满额、创建上限与失败提示仍需组合运行取证，领域/策略断言不能代替这些 UI 状态；
- 长内容与附件卡片、窄屏、最大辅助字号、VoiceOver、减少透明度、iOS 17–25 和真机手感未由本批关闭；
- 视频只证明本批抽样路径，不表示卡片堆、归入按钮或四页最终视觉已由用户冻结。
