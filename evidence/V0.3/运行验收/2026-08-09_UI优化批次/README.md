# NOTE1 V0.3 UI 优化批次证据索引

> 日期：2026-08-09
> 性质：首轮视觉与动效实现抽样，不是用户确认的最终视觉稿

## 1. 本批范围

- 统一冷调淡紫、深海军蓝、浅亮玻璃与纸张表面的主题令牌；
- 收紧卡片预览的纸张高度，强化外边距、边界、叠卡和上下换卡的前后关系；
- 将“归入构思集”中心按钮与卡片纸张语言统一，并补充点按展开、目标高亮和回收节奏；
- 将小票从普通白色长卡调整为当时的暖色热敏纸候选，并加入细齿边、虚线撕口、票据夹层次与左右换票视差；该暖色纸面随后被用户否决并由黑白热敏票据方案取代，当前结论见 `../2026-08-09_小票黑白视觉修正/README.md`；
- 细化灵感日期分组、构思集纸堆与小票页码等跨页共同语言。

本批不改变对象、容量、固定双目标、搜索、历史、保存、小票快照或其他业务规则。

## 4. 证据边界

- 截图只证明对应模拟器、字号和静态状态；录屏只证明本批采样的完整成功手势；
- 归入按钮的长按拖拽、目标外取消、首尾阻尼以及小票未过阈值回弹仍需补完整原生录屏；
- VoiceOver、减少透明度、真实附件/分享/麦克风、iOS 17–25 材质降级和真机手感未由本批关闭；
- 本目录中的“最终”仅表示本次实现迭代的最终取证轮，不表示 V0.3 视觉已经由用户冻结。
