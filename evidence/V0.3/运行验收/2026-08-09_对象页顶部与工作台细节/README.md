# 对象页顶部与工作台细节抽样

> 日期：2026-08-09
> 范围：记录灵感页与构思工作台；仅证明本批模拟器抽样，不替代真机、VoiceOver 或 iOS 17–25 运行验收。

## 本批变更

- 记录灵感页改用与现役二级页同源的 56pt 顶部框架和玻璃取消按钮；空草稿取消直接退出，有未保存内容时仍先确认放弃。
- 构思工作台改用屏幕中心标题；返回、结束本轮构思、更多使用同源独立玻璃按钮，不再由系统导航栏把右侧动作合并成不一致的胶囊。
- 记录页保存和工作台底部上下文动作限制到 1.25 倍显示字号，正文与编辑内容继续完整响应 Dynamic Type。
- 键盘工具栏、自动保存、结束确认和更多菜单的业务行为保持不变。

## 运行抽样

- 空草稿点击“取消”直接退出。
- 输入未保存内容后点击“取消”，出现“放弃本次记录？”；选择“放弃本次内容”退出且不保存。
- 构思工作台“更多”仍包含“概览与排序”“改名”“删除构思集”。
- 点击结束按钮仍出现“结束本轮构思？”确认，取消后留在当前工作台。
- 可访问性树保留“返回构思集”“结束本轮构思”“更多构思集操作”三个独立动作。
