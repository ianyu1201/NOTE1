# NOTE1 V0.3 二级页面顶部统一证据索引

> 日期：2026-08-09
>
> 性质：细节优化第八批运行抽样，不是真机或最终视觉确认
>
> 范围：全局搜索、历史中心、回收站、设置的顶部几何、按钮材质、范围标签与最大辅助字号选择态

## 1. 本批关闭的误差

- 四个全局二级页原先混用原生文字导航栏、自定义安全区栏和原生玻璃图标栏，导致标题纵坐标、关闭按钮命中区、材质和内容起点存在细小漂移；现在统一使用 `V02SecondaryPageHeader`。
- 四页共用 56pt 顶部高度、22pt 水平边距、48pt 命中区及 46pt 可见玻璃按钮；标题始终独立居中，不受左右动作数量影响。
- 各页语义不被表面统一覆盖：搜索保留“取消/选择”，历史保留返回，回收站和设置保留关闭；回收站右侧仍是更多操作。
- 全局搜索在四范围可切换时补回“当前范围”，并与历史页共用 14pt、最大 1.25 倍的上下文标签规则。
- 搜索批量选择栏属于紧凑操作区，最大辅助字号下动作文字限制为 1.25 倍，同时保留 44pt 最低命中高度和完整文案；正文与空态仍按系统动态字体增长。

## 3. 验证

- `NOTE1 Evidence iPhone 15 Pro` 与 `NOTE1 Small Evidence` 均使用当前源码构建并启动成功；
- 搜索的全部/灵感范围、进入/退出选择，历史返回，回收站关闭与更多，设置关闭及“本机隐私说明”推入/返回均通过原生运行抽样；
- 全量 XCTest：81/81 通过，0 failed，0 skipped；
- 两个模拟器取证后均恢复浅色、默认字号；主会话默认设备恢复为 `NOTE1 Evidence iPhone 15 Pro`。

## 4. 边界

- 本批只关闭 iOS 26.5 模拟器上的二级页面顶部和紧凑选择栏视觉误差；
- 不替代真机 VoiceOver 焦点顺序、触感、减少透明度或 iOS 17–25 材质降级；
- 不改变搜索、历史、回收站、设置的业务规则，也不代表四页最终视觉身份已经由用户冻结。
