# NOTE1 证据索引

> 更新日期：2026-08-03

本目录保存运行截图、录屏、日志、语义快照、同视口对照板和开发参考图。证据只证明对应提交、设备、系统和操作范围内发生过什么，不自动定义产品需求，也不自动关闭 ISSUE。

## 目录职责

| 目录 | 内容 | 使用规则 |
| --- | --- | --- |
| `V0.2/` | V0.2 模拟器、UI 审计与复验证据 | 按各批次索引理解；旧版、失败和“不采用”文件仍是历史证据 |
| `references/V0.2小票册/` | 小票册开发参考图 | 只约束文档明确映射的对象关系，不是 NOTE1 品牌确认稿 |

## 证据等级

1. 产品确认视觉：位于 `docs/02_设计/<版本>/视觉基线/`，表达目标，不证明已经实现。
2. 真实运行证据：本目录中的截图、视频和日志，表达对应构建的运行结果。
3. 外部或开发参考：`references/`，只承担指定职责。
4. 历史失败或否决证据：文件名或索引明确标注“旧版、失败、不采用”，不得作为当前通过结论。
5. 推广素材：`media/` 与 `video/`，不参与产品和工程验收。

## 使用门禁

- 引用证据时同时记录提交、设备、系统、步骤和未覆盖项。
- 模拟器截图不能替代真机、触觉、真实权限、VoiceOver 或最终分享投递。
- 目标图、候选图、运行图和推广图不得混写成同一证据等级。
- ISSUE 只有满足其现役关闭条件并经独立复验后才能标记关闭。
- 新证据放入对应版本和批次目录，并更新该目录 README 或索引。
